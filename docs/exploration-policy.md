# T-269 検証を先に、制限の判断を後に / v0.6.11

ユーザー方針（2026-10-03）：素材の役割、組み合わせ、面の形、候補、上限を先に決めつけない。試した条件・結果から、採用範囲と難易度を相談する。技術的な問題は条件と根拠を示し、エージェントの判断だけで検証候補から外さない。広場で偶然ゴールする案は発想の例であり、採用決定ではない。

## 見直した制限

ボールのおためし6／床のおためし8は「組み合わせのまま」が初期設定。本編・はじめてのあそび方・タイトルの床の練習は従来の挙動を維持。音源・音量・発音制御は変更なし。

| 既存の制限 | 現行の検証 |
|---|---|
| 減速0.2–8 | 上下限なし。スーパーボールの通常床0.2／氷0.016の差を維持 |
| 加速4–60 | 上下限なし。氷で傾きへの反応が小さい候補も丸めない |
| 反発0.7／0.9、素材0.96、スーパーボール0.94 | 上限なし。通常壁0.945／ゴム壁2.457。1を超えて加速する反発も試す |
| 素材別最高速4.5／6／6.8／8.5、共通最高速30 | 検証では速度を丸めない |
| 力場への反応倍率0–3 | 範囲で丸めない |
| 合成した力場を最も強い1個以下に丸める | 合成のまま計算 |
| 弱い反発を収束させる速度曲線 | 任意のチェック項目。初期無効、以前の体感も比較できる |
| 床スライダーの上下限 | 上限のない数値入力。空欄・計算不能な値は案内して反映しない。半径は形として成立する正の数値 |
| 素材・壁の数値が編集できない | 加速・減速・反発・力場倍率、壁・床・力場の数値を編集・共有可能 |
| ボール試遊でこけ／とげ壁が選べない | 既存6壁をすべて選択。両壁の試遊音は既存の標準壁と同じ条件（専用音色は未作成） |

「以前の調整」を比較用に残す。選ぶと弱い反発の収束も有効になり、チェックは個別変更可能。初期数値は比較の出発点であり、正式採用値や役割の決定ではない。

広場／固定シード迷路・球径0.55・7×7は既存の比較条件で、候補をこの形だけに限定する意味ではない。区画なし／少ない区画／通常の区画、自動生成の配置、偶然のゴールを含む素材別の遊び、本編の選択方法はいずれも未確定。今回の見直しから自動採用しない。

## 組み合わせと今後の候補（2026-10-03の相談）

スーパーボール＋ゴム壁は検証に残す。今回の相談では、本編の採用候補から外す方向をユーザーが提示した。物理全体を一律に丸める代わりに、組み合わせや面の仕掛けから遊びを作る。他の組み合わせも、この結果だけで自動的に除外しない。新しい吸収壁などとの組み合わせで再検討する余地を残す。

次は候補であり、まだ採用・実装・数値・優先順位を確定しない。

- コルクを基本壁にする案、げんきを回復する壁。既存コルクのdamageKは0.25だが、被弾の閾値と上限も通るため全衝突でダメージが一律4分の1になる意味ではない。
- 一部の綿の壁がへこんで反発を吸収する案。高反発の区間の中で減速・立て直しに使えるかを試す。
- 傾きでレール上をスライドするラケットのような壁。ボールと壁を同じ入力で動かす面白さ、接触中の押し出し、挟み込み、移動する壁を含む到達性は未検証。技術課題があることを理由に候補から外さない。

横方向の傾きを加えた時に元の進行速度が残り、徐々に曲がる点は実際の運動と共通。ただし本ゲームは質量・回転を解く実物の再現ではなく、素材係数を誇張した遊び。積が1を超える静止壁で衝突ごとに速くなる挙動もゲーム上のもの。通常の受動的な壁がエネルギーを生み出す意味ではない。現実の再現を必須条件にせず、面白さを検証する。

## 計算を続けられない場合

反発1倍超では速度が増幅し続ける条件がある。これも検証対象。速度を切り詰めたり、別の組み合わせへ変えたりしない。反発後の速さで移動刻みを作り直して壁抜けを防ぎ、途中のゴール通過も判定する。

数値が表現不能、残り時間を区別できない、または1回4096移動刻みでも計算が終わらない場合は一時停止。4096はブラウザを応答不能にしないための計算処理の区切りであり、速度や反発の採用上限ではない。停止理由・条件・直前の有限な位置と速度を画面／共有JSONのobservationsに残す。成功条件だけを報告しない。

ポーズ、タブ非表示時の停止、時間刻み、盤面境界・円と壁の形、到達性確認は維持。音の発音数・間隔・出力制御も既存の音声処理として維持し、動きの上限には使わない。ボールrevision6／床revision8。床のタイム記録は物理設定ごとに分け、既存記録を保持する。

採用値を変える時は、素材・床・壁・面・操作・時間の条件と結果を示して相談する。人間の面白さ、操作感、実機センサー、音の自然さは自動検証の成功と区別する。
