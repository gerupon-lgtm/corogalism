# v0.8.15 更新の確認と準備を分ける

2026-10-25、T-309。更新確認の待ち時間を改善する依頼への対応。v0.8.14までの監査で、新版の検出から全資材の保存完了まで同じ確認待ちになり、15秒で失敗表示になることを確認した。

## 挙動

| 状態 | 表示・操作 |
|---|---|
| 新版の有無を確認している | 「更新を確認しています…」。この確認通信には従来どおり15秒の上限を設ける |
| 新版を検出した | 「更新の準備中…」。資材の保存完了を待たずに確認ボタンの待機を終える。他の操作やプレイは続けられる |
| 全資材が揃った | 「更新できます。」と更新案内。適用は従来どおり本人が「更新する」を押したときだけ |
| 資材の準備に失敗した | 「更新の準備に失敗しました。もう一度確認してください。」。現在の版は継続して使える |
| 確認通信が15秒を超えた | 「通信に時間がかかっています。あとで再確認できます。」。資材準備の失敗とは区別する |

新版の資材準備そのものには確認の15秒上限を適用しない。時間切れ後に新版を見つけたり、準備が完了した場合も、現在の状態に合わせて結果文を更新する。再確認で進行中の同じ確認通信を重ねず、確認単位の監視・タイマーは終了時に片付ける。初回の「オフライン準備中」と新版の更新を分け、非対応・オフライン時の案内も維持する。

sw.jsの全資材保存、明示適用、別タブでプレイ中の適用禁止は変更しない。実際のダウンロードに必要な時間は回線等による。最新の場合にトップの位置・サイズが変わらない仕様、設定・ゲームの挙動も維持する。表示・資材URLとprecacheは0.8.15へ更新する。

旧版を開いている間は旧版の確認処理が動く。この改善はv0.8.15を適用した後から有効。
