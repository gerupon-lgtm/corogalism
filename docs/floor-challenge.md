# T-258 床素材チャレンジ / v0.6.1

## 遊びの構成

迷路はシードから生成する7×7のまま。面の形は固定しない。序盤と初登場の床は面固有の乱数列による6候補から短めの経路・適地を選び（力場適地がなければ最大24候補）、補助力場は曲がり角の内側を開けて広いカーブを作る。加工で角が経路から外れる場合は取り消して別の角を有限回試す。配置は最終BFS経路上の広い角から再選択する。

1–2面は基本、3面は砂、4面は全面氷＋全面ゴム、5面は重力補助、6面は氷＋砂、7面は反重力補助、8面は氷＋両力場。9面休憩、通常10面は「光の滑走路」、やさしい10面は氷＋砂。11面とりもち、12面石、13面重力を抜ける面、14面休憩、15面反重力を抜ける面、16面氷＋力場。以後はテーマを循環し、通常は10面ごとに専用面を挟む。

光の滑走路は複数の広いカーブ、氷・砂・重力・反重力、専用開始ジングルとゴールの光で構成。初登場は既存READY／カウントダウン内に短い絵と説明を出す。再開では紹介音を繰り返さない。やさしいは8面以上の結果画面で3回に1回だけ、滑走路の絵と光を見せる。切替ボタンや勧誘ポップアップは追加しない。

## 調整値とルール

- 氷の摩擦係数0.08。移動中の加速を最小28%へ抑え、切り返しで既存速度が残る。砂は3.2。力場の強さ±3.3、半径1.6マス。
- 力場の外周の境界線は描かず、内向き／外向きの粒子と矢印で引く・押すを表す。ポーズ中はアニメーション停止。
- コルク壁は通常と同じ反発、ダメージ係数0.25。全面氷＋ゴム以外の床面はコルク。石・トゲを床面へ混在させない。
- HPの折れ回数係数は4。通常ダメージ0.65、やさしい0.4から緩やかに上昇。接触閾値1.2、上限35%など既存衝突ルールは維持する。
- 制限時間は経路・折れ回数・砂・妨害力場・初登場を考慮。通常最低25秒、やさしい最低35秒。旧同面係数で同じ経路を走る時間＋2秒より短くしない。序盤の候補選択で長過ぎる基本面も抑える。
- キャンディ確率は通常40%、やさしい50%。停止が必要な休憩は氷や力場を避け、取得アイテムは力場中心を避ける。
- 記録は `corogalism-run-bests-floor-v1`（やさしいは`-easy`）で新旧を分離。旧記録は保持し、自己ベストの折りたたみ内へ参考表示する。

おためしページの設定は独立したまま。本編への採用は上記値であり、検証ページのダメージ変更を他面へ適用するものではない。

## ガイドと検証

ガイド冒頭に「すべる・曲がる・軌道が変わる」の絵、4床の比較、6壁、3アイテム、休憩／とりもちを掲載。見出しと閉じる操作を維持し、楽しさの伝達を優先して内部スクロールを許容する。PAUSEから閉じてもポーズを維持する。

検証記録は[床チャレンジ検証](verification/floor-challenge.md)。人間の実端末での傾きの体感と通常モードへ移りたくなる演出の評価は、公開版の試遊で追加確認する。

## v0.6.1 性能修正

静止床・壁の毎フレーム再描画を廃止し、動的な粒子・力場だけを重ねる。候補生成の増分共有による隣接面の迷路重複も解消。[検証](verification/floor-performance.md)。物理値・新記録枠は維持。

## v0.6.3 床の体験と練習

やさしいの初登場床面は最低90秒、砂3区間・重ならない力場2–3箇所にする。接触説明を無停止で表示。通常モードは従来配置を維持する。タイトルに制限なし・記録なしの「床の練習」を追加し、同じ広い面で5素材を切り替えて比較できる。詳細は[床の体験と練習](floor-learning.md)、[検証](verification/floor-learning.md)。
