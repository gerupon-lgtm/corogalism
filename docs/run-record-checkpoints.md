# T-239 ラン記録の保存タイミング（v0.4.10）

報告: ノーコンティニュー16面／コンティニュー使用12面。端末の履歴は取得できず、誤分類自体は未再現。調査でクリア直後は保存されず、終了前の再読み込みで成績が失われる経路を再現した。

- 各面のクリア直後に、コンティニュー使用有無と難易度に応じた自己ベストを保存する。
- 初回失敗までの記録はノーコン枠に残す。コンティニュー確定時に、それまでのクリア面数を使用枠にも保存する。その後は使用枠のみ更新する。
- ゲームオーバーと明示終了時にも保存し、失敗した保存を再試行できる。重複保存で今回の自己ベスト更新表示を失わない。
- 面数優先・同面数ならクリア済み面の合計タイムを比較する。失敗した面の時間は含めない。
- 既存記録の移動・削除・推測による補正はしない。2枠は独立し、後のノーコン記録が使用記録を超える場合はある。
- 保存先は従来のlocalStorage。保存を拒否された環境では保持を保証しない。ラン再開機能は追加しない。

検証: tools/browser-run-records.mjs。修正前にクリア直後の未保存で失敗。修正後にやさしい／通常のクリア・続行確定・結果・再読み込み・別ランの記録分離を確認する。
