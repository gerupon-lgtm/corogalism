# T-297 / v0.8.3：盤面直前までの黒い領域と、葉っぱの取得不可案内

2026-10-24。ユーザーが「ヘッダー」はロゴ行だけでなく、プレイ盤面が始まるまでの黒い領域全体を指すと明確化。0.8.2でロゴ行だけを基準にした対応を訂正し、トップ木枠の上端をチャレンジ盤面の上端と合わせる。併せて、葉っぱを取れない理由の表示と、ルールの資料整理を依頼。

## トップの上端

トップでも、元のげんき・残り時間・面数・操作列を透明な予約領域として残す。複製したメーターや操作部品は作らない。表示はせず、読み上げ・フォーカス・操作の対象にも含めない。行の高さやフォント・カメラ余白・幅の条件を実際のチャレンジと共有する。

狭い画面では面名の折り返しも行の高さを変えるため、次に開始するチャレンジ1面目の表示文言を同じ生成処理で下見し、透明な操作列へ使う。下見は独立したランで行い、本番の進行・種・選曲・記録・げんきは変えない。練習・紹介の盤面位置自体は従来どおり。紹介からタイトルに戻ったときは、紹介用の1列メーターの指定を引きずらない。

木枠の横幅は0.8.2の共有式を維持し、上端もチャレンジ盤面に合わせる。空きが減るため、入りきらない端末ではボタンを縮めず自然なスクロールを許す。使用できる高さに合わせた拡大分は、増えたヘッダー領域も考慮する。トップからゲームへ移る際は、タイトルをスクロールしていても表示位置を先頭に戻す。設定から戻るときの位置保持は維持。

## 葉っぱを取れない理由

ユーザーが求めたのは上限数値の追加ではなく、キャンディと同じ取得不可の案内。まもりがその面の追加上限以上のとき、未取得の葉っぱに触れると「葉っぱのまもりはまんたん！」を盤面外の既存案内に表示する。触れ続けている間は繰り返さず、離れて戻ると再表示する。追加SEは鳴らさない。

葉っぱは盤面に残り、まもりが上限未満になれば同じ接触中でも取得可能。げんき満タンでもまもりに空きがあれば取得できる。既存の取得量20%・追加上限50%・持ち越しは変更しない。HUDに新しい数値や欄は追加しない。

## ルール資料

[player-rules.md](player-rules.md)に、げんきとまもりの違い、アイテムの取得条件と取れない理由、持ち越し・コンティニュー・回復と時間・モード差を整理。現実装と旧資料の差は現在のコードを優先して明記する。今回の資料整理でルールを変更しない。
