# T-225 チャレンジの遊びやすさと面テーマ

2026-09-13。ユーザーと相談して今回の実装範囲を確定。公開・検証状況は末尾に記載する。

## 難易度と記録

- チャレンジに「やさしい」「通常」。既定は従来どおり通常、選択を保存。
- やさしいは既存の衝突ダメージと単発上限をともに50%にする。通常100%。閾値1.2と無敵時間は維持。
- 時間制限、HP初期値、物理、7×7迷路と壁配置は難易度間で共通。
- 各難易度にノーコン／コンティニュー使用の2記録、計4枠。表示は選択中の2枠。「自己ベストを見る」で開閉し、初期状態は閉じる（ユーザーの追加指示）。
- 通常の保存キーは維持して既存記録を引き継ぐ。やさしいは別キー。結果画面に難易度を表示。

## 包みキャンディ

- 比較画像A。緑×クリームの斜め縞と左右のねじり包み。光沢、控えめな発光・浮遊。Canvasで小さくても判別できるよう描画。
- 面ごとに最大1個。やさしい50%、通常20%で出現。取得後その試行中の再出現なし。
- ゴールへの正解経路の55〜85%地点のセル中心。スタートとゴールは除外。
- 迷路シードから独立系列で抽選。同じ面・難易度のやり直しで出現と位置は同じ。コンティニューは従来どおり面を初期状態へ戻す。
- 最大HPの20%を回復、満タンを超えない。満タン時は残す。死亡・時間切れが優先、復活には使わない。
- 被弾履歴を維持し、回復でノーミス扱いにはしない。
- 取得時は実回復量を盤面内に短く表示し、ゲームを止めない。既存の軽いSEを再利用。音OFFは無音。
- 確率・回復率・配置範囲などはgameConfigで調整可能。

## 面テーマとゴム壁

- 1・2面は基本（標準のみ）。以後は8面周期で「やすらぎ・はずむ・慎重・基本・やすらぎ・はずむ・慎重・腕試し」。初めてのトゲは10面目。
- 特殊素材は1面につき1種類。標準と苔45%／ゴム30%／石22%／トゲ12%。割合の母数は配置候補の内壁。
- 外周とスタート・ゴールに接する壁は標準。正解経路の曲がり角周辺を優先し、シードで決まる順に配置する。
- ゴムの既存反発1.5倍・ダメージ係数0.4を使用。全面ゴムにせず、落ち着ける標準壁を残す。
- 面番号でテーマが固定され、リトライ時に変わらない。迷路の形は各ランのシードで変わる。
- プラクティスは従来どおり標準壁のみ。面テーマはプレイ操作バーの左に表示する。
- 旧difficultyAtと素材配置は基準検証用に保持。本番はchallengeDifficulty経由。

## 傾きの基準

- ページを開いて最初の傾きプレイだけ、READY中に0.5秒の安定姿勢を平均して採用（2度以内、最低5サンプル）。基準設定後に通常READY→3カウント。
- ページ内の次面・コンティニュー・モード変更・再挑戦で基準を維持。継続的な自動補正をしない。
- 保存済みの古い姿勢を別の持ち方に押し付けないよう、ページ再読み込み時は改めて取得。
- プレイ画面の基準ボタンはポーズして測定。ポーズ内にも「この角度を基準にする」を用意。完了後も手動再開。
- センサー初期化後は設定からも明示測定できる。初回プレイ前は測定ボタンを無効にし、モード選択時にセンサーを確認する旨を表示。中断すると以前の基準を維持。非表示中は採用しない。
- 許可拒否・センサー無応答は従来のタッチ操作へ。姿勢が安定しない間もREADY内の「タッチで遊ぶ」から切替可能。
