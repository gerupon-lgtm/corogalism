# T-262 はじめての床体験とやさしいの時間（v0.6.4）

ユーザー承認：各種要素を「はじめてのあそび方」に入れ、やさしいの制限時間を妥当なラインに調整する。「床の練習」は現在のまま。

- チュートリアルの同じ7×7の広い蛇行面に、砂・氷・重力・反重力・コルク壁を追加。6壁・6床／しかけ・3アイテムを体験できる。時間制限なし、げんき下限1、記録なし。物理係数は本編と同じ。
- 砂は上段の短い区間、氷は中段。重力は上段の右、反重力は下段の右。影響範囲を重ねず、アイテム／休憩／とりもちを力場から離す。葉っぱは(3.5,2.5)、砂時計は(2.5,5.5)へ移す。休憩・とりもちと助走先のゴム／トゲは従来位置。氷に接する下側の壁1区間をコルクにする。
- 既存の0.7秒後の接触説明・無停止・説明保持・更新時の金色表示を新床にも適用する。ガイドと共通の絵・本文を使用し、ポーズ・非表示・カウント中は進めない。
- やさしいの時間は最低40秒、床の初登場は最低45秒。一律90秒を解消。経路1マスにつき1.6秒、折れ点1箇所につき1秒、進路確認8秒、砂1マスにつき0.8秒、力場1箇所につき1.5秒、初登場6秒を基準に、既存の時間保証も下回らない。整数秒へ切り上げる。長い経路には長い時間を与え、絶対上限は設けない。
- 通常モードの時間計算・本編の生成・床や壁の物理／HP・記録キーは維持。床の練習の面構成・切替・操作・制限なしも維持。

短い基本面でも35秒では、遅い入力と進路確認を含む操縦に不足したため、最低値だけでなく経路／折れ点の計算を見直す。操縦モデルは人間の傾き体感を保証するものではない。ブラウザの実pointerと個別機能確認を分けて検証し、公開後に実機体感を追加調整する。
