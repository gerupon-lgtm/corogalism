# v0.8.19 やさしいのげんきに余裕を持たせる

2026-11-06。壁への衝突では、げんきの減少量と球の跳ね返りを別々に計算している。このため、転がる速さや滑りを保ったまま、チャレンジ「やさしい」で失敗までに立て直せる回数を増やす。

## 変更する値

やさしいのダメージ係数を0.40から0.28へ変更し、序盤の軽減がなくなる面を10面目から24面目へ延ばす。軽減は面ごとに少しずつ減らす。通常は係数0.65・10面目で軽減終了のまま。

| 現在の設定 | やさしい | 通常 |
| --- | ---: | ---: |
| ダメージの難易度係数 | 0.28 | 0.65 |
| 序盤の軽減がなくなる面 | 24面目 | 10面目 |
| 1回の衝突で失う上限 | 初期げんきの5.6〜9.8% | 初期げんきの13〜22.75% |

実際の減少量は「速度と壁素材から求める量」と「その面の単発上限」の小さい方。葉っぱのまもりがあれば、先にまもりが引き受ける。やさしいは24面目以降、同じ衝突の減少量と上限が従来の70%になる。2〜23面では、延長した序盤軽減も重なる。

初期げんき40＋4×曲がり角の回数、無傷となる速度の境界1.2マス/秒、被弾間隔0.25秒は維持。通常の難易度、制限時間、迷路と仕掛けの生成、転がり・反発・滑り、回復・葉っぱ、記録の保存先と既存記録は変更しない。画面の版表示と資材の更新識別子はv0.8.19へ更新する。

11面目・初期げんき140・通常壁・まもりなしで、0.5秒ごとに同じ強さで衝突させた。11面目の新しい単発上限は初期げんきの約7.43%、140なら約10.4。丸め前の数値は比較データに残す。
