# C案のビジュアル実装（v0.2.2）

ユーザーが比較画像のC案を全項目で選択。参照は `design/2026-09-12-visual-proposals/`。

追加依頼で比較画像左下の葉マーク＋Corogalismも採用。SVGの葉と文字で見出し・フッターへ再現した。フッターは原案の「A SMALL MAZE / A BIG FEELING」を併記する。

## 表示と動作

- クリア／コンティニューは盤面の中央へ重ねる操作付きトースト。位置はユーザーの追加指示で中央に確定。クリーム色の面、オレンジの縁、立体的なボタンと短い登場アニメーションをC案に合わせた。
- 終了時もゲームHUD・下部パネルを同じ場所に保持する。下部の操作をinertにし、フォーカスはpreventScroll付きでトーストへ移す。Tabはトースト内で循環する。
- トーストは操作まで消えない。継続不能時は結果ボタンを主操作にする。練習では同じ迷路のリトライも残す。
- ゴールはクリーム色の縁、オレンジの内側、チェック模様のカップ。クリア後520msで球を中央へ収め、1500msの紙吹雪を描く。
- 球はオレンジ／クリームの曲線模様とパール調の光沢。移動距離÷半径を回転角とし、移動方向に直交する軸のクォータニオンを積算する。表面模様は回転し、光源は左上に固定する。
- 標準は丸い縁と溝、石は成形ブロックと小孔、棘は赤い面と内側の三角模様、苔は小さな葉と斑点、ゴムは青い面とくぼみ。ユーザーの再現度の指摘を受け、C案を基に作った同梱テクスチャ `assets/toy-wall-atlas.png` に差し替えた。接地影で厚みを補い、白い輪郭線を重ねない。凡例も同じ画像を使う。
- TIME・HPも追加指示でクリーム色の丸い枠、オレンジ／グリーンの立体ゲージに統一。時計・ハートのアイコンと数値を併用し、低残量・被弾も色と数値で伝える。下部のタイム等も同じ色調。
- `prefers-reduced-motion: reduce` ではトーストの登場・ゴールの補間・紙吹雪を省き、到達時の静止表示にする。球の転がりはプレイ中の移動を伝える表示として維持する。

## 実装の境界

`canvasRenderer.js` が盤面のキャッシュ、`toyWorld.js` が床・壁・カップ・紙吹雪、`toyBall.js` が球面描画、`ballRotation.js` がDOM非依存の回転計算を持つ。

画像の壁サンプルは拡大図のため、現行の壁厚0.10セルに合わせてテクスチャを縮小する。壁面は衝突矩形内にクリップし、接地影のみ外側に落とす。ゲームの物理・難易度・迷路生成・素材配置・保存形式は維持した。球がカップに収まる補間はクリア判定後の描画だけで、物理座標を変更しない。

テクスチャ読込時に盤面キャッシュを更新し、読込失敗時は素材別のCanvas描画へフォールバックする。

球スプライトは最大96×96pxで生成し、停止中は再生成しない。盤面は面／サイズが変わる時だけ描き直す。ゲームの実行時に画像生成や外部API、追加ライブラリは使わない。

- `node --test`: 78件成功。新規2件は90度転がり・逆走・多数回の回転による長さ保存を確認。
- `tools/browser-smoke.mjs`: 練習、入力、停止、クリア、時間切れ、2回までのコンティニュー、記録分離、保存再読込。
- `tools/browser-edge-cases.mjs`: 実際の物理でHP0、回復、後半素材、センサーの許可分岐、保存不可。
- `tools/browser-toy-visuals.mjs`: 320／375／390／1280px幅でクリア・次面・失敗・コンティニュー前後の盤面座標、スクロール位置、文書の高さが完全一致。実クリック・Tab循環・トースト保持・タイマー停止・動きを減らす設定・練習リトライも確認。
- 画像: `verification/toy/`。実機の見た目・転がりの体感・描画速度の最終判断はユーザー試遊で確認する。
