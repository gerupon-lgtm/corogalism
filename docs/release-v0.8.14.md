# v0.8.14 設定の見出しをトップへ正確に合わせる

2026-10-25、T-308。設定画面のタイトル周辺の位置とサイズをトップに合わせる依頼。

修正前の393×740では、フォントは両方26pxだったが、設定のタイトルと小物は3px下、壁ラインは4px下にあり、左右の余白も1pxずつ異なっていた。設定側が独立した見出し用の余白・高さ・配置を持っていたことが原因。

設定の外枠・内側の余白・見出し行をトップと共通のおもちゃ箱スタイルへ変更し、設定専用の重複指定を削除する。文字列が異なるため文字そのものの横幅は同じにせず、文字の中心・上端・高さ・フォント、小物2点の位置と寸法、壁ラインの位置と寸法を一致させる。操作部分のコンパクトな配置とボタンサイズを維持する。トップ・本編・物理・BGM・記録と、更新チェックのロジックは変更しない。表示・資材URLとprecacheは0.8.14へ更新する。

更新確認が遅い件は別途[監査資料](update-check-audit.md)にまとめた。新版の有無だけでなく全資材の準備を待つ動作と、15秒の時間切れ後も準備を継続することを実ブラウザで確認済み。更新処理の変更は未実施。
