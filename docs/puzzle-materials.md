# T-291 動く壁と床・壁の組み合わせ / v0.7.2

## ねらい

通常床は球を落ち着かせ、氷は勢いを残し、砂は一部で強く減速させる。同じ傾きで球と壁を動かす遊びに、床と固定壁の違いを加える。やさしい・通常の両方で、後半を一律に難しくせず、普通の迷路・単独の仕掛け・組み合わせ・息抜きを混ぜ続ける。

## 紹介とげんき

「動く壁のあそび方」の最初の２面は全面通常床・固定壁はすべて通常壁。ラケットと通路の戸は従来の専用設定を使う。３面目からは氷・ゴム・綿の土台で、勢いを残して切り返す操作を紹介する。

ユーザーの追加指示により、紹介中も壁の素材と衝突速度に応じてげんきが減る。「減らさない」という直前の方針は取り消した。基本のあそび方も含め、げんきは０まで下がるが操作とクリアを続けられ、０からキャンディ・ひとやすみで回復できる。説明は「げんきが0になっても続けられます。」。時間制限はなく、既存150pxの説明枠に目的・操作ヒント・注釈を表示する。

本編の０で終了する判定と、終了後に回復させない扱いは維持する。通常壁のダメージを消したり、無傷の壁として描いたりしない。練習・素材の検証ページのルールは変更しない。

## 本編の配分

17／19／21／23面の初紹介は、従来の氷・ゴム・綿を使う。24面以降は直近の面と素材を考慮して、次の６種類を抽選する。

| 組み合わせ | 床 | 固定壁 |
| --- | --- | --- |
| 氷と無傷の壁 | 氷 | ゴム・綿 |
| 氷と砂で緩急 | 氷・一部砂 | ゴム・綿 |
| 落ち着いて操作 | 通常床 | ゴム・綿 |
| 通常床と砂 | 通常床・一部砂 | コルク主体・綿・一部ゴム |
| 氷と砂、低ダメージの壁 | 氷・一部砂 | コルク主体・綿・一部ゴム |
| 床と壁の混在 | 通常床・氷・一部砂 | 通常壁・コルク・ゴム・綿 |

32面までは無傷の壁の組み合わせの重みを増やす。その後も同じ候補を使い、安全な面を残す。難しい組み合わせを連続させる固定巡回や、面数に比例して素材の危険度を増す方式にはしない。これらは公開の初期配分であり、検証ページで試せる候補の制限ではない。

## 配置・時間・計算

砂はラケット付近や戸の待機位置などへ分散させる。砂は球の減速に効き、ラケットの移動速度には効かない。切り返しの助走と開口の周辺には砂を重ねず、混在床ではその区間に氷を残す。全面通常床の組み合わせも候補に含め、動的な通過は別に検証する。

砂と氷を同じマスに重ねない。通常床は特別な床のゾーンを持たず、従来の通常素材で計算する。床・壁の物理値、ラケットの反発と打ち分け、球の傾きによる加速の仕組みは維持する。

初期げんきは従来の経路の折れ回数で計算する。制限時間も従来の経路・曲がり・動く壁の操作負担を使い、経路上の砂を既存の加算へ含める。コンティニューは同じ種・素材・仕掛けを再現する。既存の記録を消さない。

## 確認の扱い

静止壁の到達性と開口の球径確認、床・壁の決定性、数値入力による通過、ブラウザの実pointer操作を分けて確認する。失敗した操作も残し、以前の氷用入力が失敗しただけで通常床を遊べないと断定しない。Pixel 6a実機での傾き、読み取りのタイミング、長く遊んだ時の緩急や楽しさは別の試遊が必要。
