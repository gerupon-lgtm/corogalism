# T-237 画面高を使う配置とPAUSEガイド（v0.4.8）

ユーザーの補足: 全体を小さくして黒い空白を増やすのではなく、画面高を使い1画面に収める。プラクティスも対象。狭い端末でプレイに影響を出さない。

- wrapに100dvhの最小高。トップ・設定・結果・プレイ下部のパネルへ残り高さを配分し、既存の世界観とコントロールを維持。
- 迷路の従来の幅・縦横比・最小200pxを維持。狭い端末や文字拡大で収まらないときは自然スクロールを許可し、操作をつぶさない。
- チャレンジの壁の見分け方は削除し、ガイドに一本化。
- PAUSEにあそびのガイドを追加。ガイドを閉じるとPAUSEへ戻り、起点のボタンにフォーカス復帰。再開の明示操作まで物理・時間を停止。
- PAUSEボタン群もトイ調に統一。小さな迷路ではトースト内部スクロールで全操作へ到達できる。

高さ800px以下では画面間隔を少し詰め、迷路直下の重複した操作案内を省略。PAUSEのガイドから説明を読める。
