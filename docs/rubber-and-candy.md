# T-238 ゴム反発と満タン案内（v0.4.9）

ユーザー最終確定: ゴム自体は無傷、反発した先の別の壁でダメージ。説明も合わせる。

- ゴムの素材倍率2.0→2.6。resolveParamsを通しゴム専用上限0.9へ、他素材は上限0.7を維持。
- ゴムdamageK=0。げんき・葉っぱのまもり・ノーミスへ影響なし。無傷のゴム接触でダメージ無敵時間を開始しないため、すぐ先の石やとげでは通常判定。
- 反発距離は衝突速度・傾き・摩擦・他の壁に依存。空間があれば約1マス以上反発できる。固定距離のワープや操作の強制停止は行わない。
- 数値計測（dt=1/120、初速3、無入力、摩擦2.5）: 衝突速度約2.94マス/s、1.5秒後の反発距離約1.02マス。壁へ傾け続けると短くなる。実機の慣性の感じ方は引き続き調整可能。
- キャンディは満タン時に残す。接触開始で一度「げんきはまんたん！」と表示し、接触継続中は繰り返さない。いったん離れて触れ直すと再案内。満タン案内では取得SEを鳴らさない。
- ガイド: ゴム「ゴムは無傷。次の壁に注意。」、キャンディに「満タンなら残る。」を追記。
