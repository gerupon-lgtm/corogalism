# T-275 / v0.6.17 終了と分かるボタンと確認（2026-10-05）

「結果を見る」は成績表示後に元の挑戦へ戻れず、終了する操作だった。次へ進むボタンの待機中に誤って選びやすいという報告を受け、ユーザーが選んだ1案を実装する。

- チャレンジのクリア・プレイ中のボタンを「終了して結果を見る」に統一。コンティニュー可能な失敗画面も同じ表記。
- 押すとクリーム色の確認画面で「ここで終了しますか？」と表示。「戻る」を最初に選ばれる操作にし、「終了して結果を見る」の確定後に結果へ進む。
- 「戻る」やEscapeで取り消せる。元の画面・面数・成績・げんき・コンティニュー回数を保つ。確認中は背景の操作を受け付けない。
- クリア・失敗画面は切り替えず、ジングルと既存の待機を継続。取り消しても待機を最初からやり直さない。有効化時の300msの彩度復帰を維持。
- プレイ中に開くと一時停止。取り消した後も停止を維持し、本人が「再開」を押すと従来のREADY・カウントで戻る。
- コンティニューを使い切り、続けられない場合は従来の「結果を見る」から直接結果へ。練習・チュートリアルのモード選択へ戻る操作も従来どおり。
- チャレンジの現在の面数は、盤面と残り時間・げんきの表示より上の「○面目」で引き続き確認できる。

実装は`src/ui/runEndConfirm.js`、`src/main.js`、終了ボタンの表記・HTML・CSS。[検証・公開状態](verification/run-end-confirm.md)。以下は変更履歴。

# T-274 / v0.6.16 無効なボタンの色と有効化（2026-10-05）

色が急に戻ると切り替えが唐突に見えるため、無効なボタンを完全なグレースケールにし、有効化から300msかけて元の彩度へ滑らかに戻す。結果画面では明るさも同じ時間で戻す。色が戻る途中から操作を受け付ける。

- ボタン名・位置・寸法と、通常クリア2秒／光の滑走路0.65秒／コンティニュー1秒の待機を維持。追加文言・バーは付けない。
- 動きを減らす端末設定では、従来どおり色の切り替えを即時にする。
- 「結果を見る」がチャレンジを終了する既存の挙動は、この色変更では改修していなかった。1案の承認後、T-275で終了と明記して確認する形へ改修。

実装は`style.css`。ブラウザでの彩度の途中値・操作・公開状態は[グレースケールの検証記録](verification/end-grayscale.md)。以下は変更前の仕様。

# T-273 / v0.6.15 結果画面でジングルを聞く間（2026-10-05）

ジングルと結果画面を味わい、次へ進む前に短い間を作る。カウント後の既存の間と同じ意図。音が鳴り終わる少し前から次の操作を受け付ける。

| 場面 | 画面表示からボタンが有効になるまで | ジングルの終了 |
|---|---|---|
| 通常のクリア | 次の面／次の迷路へ進むボタンは2秒 | 約2.23秒（開始の間0.18秒＋音2.05秒） |
| 光の滑走路のクリア | 0.65秒 | 約0.9秒（0.18秒＋音0.72秒） |
| ゲームオーバー | コンティニューは1秒 | 約1.3秒 |

- ボタン名・大きさ・位置を保ち、待機中は少し薄く、オレンジの鮮やかさを控えめにする。有効化で160msかけて元の明るさと色へ戻す。追加文言・バーは付けない。動きを減らす端末設定では色の切り替えを即時にする。
- 音OFF、音声機能のない端末、音源の読み込み失敗でも同じ待機時間。音の終了通知に依存して操作不能になる仕組みにはしない。
- 待機中のタップとキー入力では次の面に進まず、残りコンティニューを消費しない。別画面へ移ったら待機を取り消す。コンティニューを使い切った場合は、従来どおりボタンを表示しない。
- チャレンジの通常／やさしい、プラクティス、床の練習、チュートリアルの同じ「次へ」ボタンへ適用する。チュートリアルではモード選択へ戻る操作が対象。
- 結果を見る／終了する／同じ迷路をやり直す操作は従来どおり。ジングル、既存のREADY・3・2・1・カウント後の間、物理、制限時間、記録計算は変更しない。

実装は`UI.clearButtonWaitMs`／`specialClearButtonWaitMs`／`continueButtonWaitMs`、`src/main.js`、`style.css`。検証・公開状況は[結果ボタンの検証記録](verification/end-actions.md)。

# T-223 / v0.2.10 ラン結果と開始前の間（過去の変更）

ユーザーのラン結果スクリーンショット（v0.2.9）の暗いパネルを現行のトイ調へ揃え、コンティニュー直後にカウントが始まる慌ただしさを調整。

- ラン結果はクリーム色の立体パネル。クリア面数を大きく、タイム・ノーミスを明るいカードに表示。自己ベストは緑、新記録バッジは金色。
- 結果へ移ったときは先頭へスクロールして見出しにフォーカスし、小さい画面でも結果の冒頭から読める。
- 再挑戦・モード選択は縦並びの丸いボタン。既存のM PLUS 1pを使用。結果画面では迷路・HUD・操作説明フッターを表示しない。
- モード選択から開始、次面、リトライ、新しいラン、ポーズ再開は0.6秒のREADYを挟み、その後3・2・1。
- コンティニューは1.5秒のREADY（専用SE1.3秒＋余裕0.2秒）の後に3・2・1。音OFFでも同じ長さ。
- READYとカウント中は入力・物理・HP・時計を停止。待機中のポーズ・設定・非表示タブでも進めず、再開操作で新しいREADYから始める。別画面からタイマーで勝手に戻る処理は使わない。
- カウント後のスタートSE0.8秒＋間0.2秒、その後のBGM先頭再生・ループは維持。操作開始はカウント終了時。
- 検証中注記・noindexを維持。記録計算・保存カテゴリは従来どおり。
