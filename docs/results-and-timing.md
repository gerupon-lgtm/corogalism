# T-223 / v0.2.10 ラン結果と開始前の間

ユーザーのラン結果スクリーンショット（v0.2.9）の暗いパネルを現行のトイ調へ揃え、コンティニュー直後にカウントが始まる慌ただしさを調整。

- ラン結果はクリーム色の立体パネル。クリア面数を大きく、タイム・ノーミスを明るいカードに表示。自己ベストは緑、新記録バッジは金色。
- 再挑戦・モード選択は縦並びの丸いボタン。既存のM PLUS 1pを使用。結果画面では迷路・HUD・操作説明フッターを表示しない。
- モード選択から開始、次面、リトライ、新しいラン、ポーズ再開は0.6秒のREADYを挟み、その後3・2・1。
- コンティニューは1.5秒のREADY（専用SE1.3秒＋余裕0.2秒）の後に3・2・1。音OFFでも同じ長さ。
- READYとカウント中は入力・物理・HP・時計を停止。待機中のポーズ・設定・非表示タブでも進めず、再開操作で新しいREADYから始める。別画面からタイマーで勝手に戻る処理は使わない。
- カウント後のスタートSE0.8秒＋間0.2秒、その後のBGM先頭再生・ループは維持。操作開始はカウント終了時。
- 検証中注記・noindexを維持。記録計算・保存カテゴリは従来どおり。

実装: `src/config/gameConfig.js` の `UI.beforeCountdownMs` / `continueBeforeCountdownMs`、`src/main.js` のprepareMs、`index.html` / `style.css`。
