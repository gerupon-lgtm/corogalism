# T-260 ダメージ表示の重なり修正（v0.6.2 / 2026-10-02）

ダメージ量のabsolute配置（top:-10px）がげんき枠の上辺と重なり、読みにくかった。ダメージ要素を「げんき」の見出しから分離し、既存2段目の左側へ独立した小さな淡色ラベルで配置。残りげんきは同じ段の右側、葉っぱのまもりは上段に置く。表示／非表示でHUDや盤面の高さを変えない。物理・HPの計算・表示値・表示時間は変更しない。

browser-hp-display.mjsに、実際の壁衝突で表示中のダメージ量が枠内4px以上に収まり、見出し・HP数値・まもり・ゲージと交差しない確認を追加。修正前は320幅の枠内条件で失敗、修正後は成功。320×568、390・576・1280×844で、整数減少と「微小」の両方、表示値と実HPの対応、横はみ出しなしを確認した。

[320幅・整数ダメージ](hp-display/integer-320.png)、[390幅・微小ダメージ](hp-display/tiny-390.png)。スクリーンショットも目視で確認。
