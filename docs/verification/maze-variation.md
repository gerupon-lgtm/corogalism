# T-278 / v0.6.20〜v0.6.21 迷路バリエーションの確認

## 確認の前提

最終形の経路へ、既存の時間・初期げんき・ビー玉の物理を適用する。やさしい107面までの単調さが動機なので、序盤だけでなく100面前後の選択と操作も対象にする。

操縦モデルは最短経路を知っている。人間による道探し・集中力・面白さを保証する検証ではない。Chromeの処理時間も実スマホのFPSではない。失敗した条件を削除せず保存する。

## 生成と操縦モデル

`node tools/verify-maze-variation.mjs`。両難易度×4種のラン×150面の選択を記録。実際の操縦は各ランの1〜16・17・23・29・40・64・100・107・125面、2種類の操作モデルで384条件を比較する。

- 通常操作モデル: 約0.18秒ごとに向きを直し、ときどき入力をずらす。
- 慎重操作モデル: 約0.30秒ごと、低めの速度、経路4点ごとに0.6秒の考える間を入れる。

| 難易度 | 通常操作モデル | 慎重操作モデル |
|---|---|---|
| やさしい | 96/96クリア | 89/96クリア、時間切れ7 |
| 通常 | 96/96クリア | 35/96クリア、時間切れ60・げんき切れ1 |

合計316/384クリア。失敗も残し、通常の慎重モデルに厳しい条件があることを実機試遊の対象とする。今回の指定に従い、失敗を消すために時間・げんきの既存計算を変えていない。結果は [summary.json](maze-variation/v0620/summary.json)、個別の失敗を含む [balance.json](maze-variation/v0620/balance.json)、150面の並びは [campaigns.json](maze-variation/v0620/campaigns.json)。

## 一定傾きでの直行

7・9・11・13・17・21の広場、3種、10テーマ（砂・石・トゲ・こけ・とりもちとの組合せも含む）、96方向、強さ0.1・0.5・1を比較する。最初の反発まで最大20秒を進め、移動区間がゴールを通過したかを調べる。51,840条件で最初の反発より前のゴールは0件。

これは一定の傾きでの確認。人が傾きを変えて壁を避けるクリアを禁止する試験ではない。全角度の数学的な網羅や、実機のセンサー誤差の確認とも区別する。
