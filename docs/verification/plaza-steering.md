# T-283 広場の切り返しの確認 / v0.6.26

2026-10-08。仕様は[広場での切り返し](../plaza-steering.md)。実装とローカルの最終確認を完了。公開URLの追加確認は配信後に追記する。

## 原因と変更前の再現

v0.6.25の生成コードでは主な仕切りが1本、短い追加壁の候補が片側に限定されていた。7/9/13/21×種5/77/913/7919の16配置すべてに、外周をL字に進める道が残っていた。

新しい検証で「両方のL字近道を遮る」「マスに沿う経路でも複数回切り返す」「増えた空間にも床がある」の失敗を確認してから修正した。道順を最短で探す処理の選び方に依存しないよう、方向変更の最少回数も別に調べる。7/8/9/11/13/15/17/21×24種では、マスに沿う道は最少4回以上。自由な斜め移動の方向変更を数える検証とは異なる。

## 自動確認と難易度

- 全35ファイルを5ファイルずつ7回に分け、196/196成功。到達性・再現・素材・時間とげんき・取得物・休憩の継続・通知などを確認。[最終結果](plaza-steering/v0626/node-batches-final.json)。
- 8サイズ×40種の320配置で、変更前のL字近道は320/320、変更後は0/320。[配置比較](plaza-steering/v0626/layouts.json)。
- 広場だけの576操縦。やさしいの180ms操作144/144、300msで考える間を置く操作140/144。通常はそれぞれ80/144、12/144。通常の失敗が多いことも含め、200失敗を削除せず保存。[全結果](plaza-steering/v0626/plaza-balance.json)、[集計と失敗](plaza-steering/v0626/plaza-summary.json)。やさしいの4失敗は17/21の大盤面と砂／邪魔をする重力での慎重な操作。これを理由に候補から外していない。
- 普段の面選択8ラン×150面で大小・長短の混在を確認。操縦384条件はやさしい180ms96/96・慎重91/96、通常180ms96/96・慎重25/96。76失敗を保存。[結果](plaza-steering/v0626/campaign-check/summary.json)。以前の同じ選択の319/384から308/384へ変わり、やさしいの成功数は同じ、通常の慎重操作の失敗が11増えた。ルールの式を変えて失敗を隠す調整はしていない。
- 7/9/11/13/17/21、3種、10床テーマ、96方向、入力0.1/0.5/1の51,840条件で、壁に反発する前のゴールは0。本編の停止・脱出・回復・延長・通過ゴールを含め、各面の制限時間まで進めた。[同じ集計](plaza-steering/v0626/campaign-check/summary.json)。

モデルは道順を知っている。慎重なモデルは1マスごとに減速するため、広い直線を続けて転がす人間の動きと違う。通常を含めた人間の難易度評価の代わりにはしない。

## ブラウザ操作と修正

- 印の修正前のChrome実pointerは34面中33クリア。やさしい18面はすべてクリア。通常52面は25.3秒＋延長5秒で時間切れとなり、失敗を保存。[慎重な操作](plaza-steering/v0626/game-local/results.json)。
- 直線の途中で毎マス止めず、角へ向けて転がす操作で、先にゴムへ反発させてから両モード各6面、12/12クリア。通常52面も18.5秒でクリア。[印の修正前の反発操作](plaza-steering/v0626/game-flow-local/results.json)。
- 全体を調べる過程で、短い壁が力場の印に重なる45例を発見。失敗する検証を追加してから配置を修正。7/8/13/21×100種の400配置・4,110の印で重なり0、各空間の両向きの力の欠落0。[印の確認](plaza-steering/v0626/marker-audit.json)。
- 最終コードをPixel 6a相当の412×915、DPR2.625で操作。両モードの3/16/52面、6/6クリア。通常52面は18.27秒、延長込み30.3秒。両モードの13×13広場も22.77秒でクリアし、2回の反発を立て直した。[最終6面](plaza-steering/v0626/game-final-local/results.json)、[13×13](plaza-steering/v0626/game-13-local/results.json)。未選択の面送りは位置移動で省略し、実プレイに数えない。実機のセンサー入力ではない。
- 320/412/576幅×6配置の18画面で、各空間の砂・力場・休憩・とりもちと作用を確認。[配置診断](plaza-steering/v0626/scenes-local/results.json)。
- 107資材を保存後に通信を切り、5床の盤面外通知、BGM、ポーズ・ガイド、両おためしと本編の新しい広場の生成・実pointer移動を確認。[オフライン](play-notices/v0626/local-offline.json)。

## 負荷と配置の維持

同じ空間・半径の配置候補を繰り返し調べていたため、一度調べた結果を使い回すように変更。51,840条件に使った180面の全配置のSHA-256が最適化前後で一致した。力場の数や性質を減らす変更ではない。[配置の一致](plaza-steering/v0626/layout-optimization.json)。

PC版ChromeのCPU処理を6倍遅くし、412×915・DPR2.625で確認。最適化前は7/13/21の生成91.5/242.5/1,228.8ms。最適化後は65.2/80.7/544.3ms。最終版の更新＋描画中央値8.5/17.1/18.9ms、95％点18.8/24.3/30.5ms。v0.6.25の同じ回の中央値7.6/11.8/12.7ms、95％点15.7/23.9/26.8msで、力場などが増えた分の負荷は残る。[最適化前](plaza-steering/v0626/performance/results.json)、[最終測定](plaza-steering/v0626/performance-optimized/results.json)。単発の代表測定であり、実機のFPS・発熱・長時間の動作を保証しない。
