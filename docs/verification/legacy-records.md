# T-292 旧ルールの自己ベスト表示 / v0.7.3

## 原因と修正

保存先は初期ルール・床追加後・迷路の変化追加後・動く壁追加後の世代で分かれている。旧記録欄は迷路世代が一つでも有効ならその世代だけを選ぶため、床世代の107面が保存されていても、新しい旧世代の16面に隠れた。記録の消去ではなく、表示対象を選ぶ不具合を再現した。

旧記録の３世代をすべて読み、やさしい／通常、ノーコン／コンティニュー使用の各枠で面数を優先、同面数は速い方を参考用自己ベストとして表示する。文言は「旧ルールの自己ベスト」。読み取りだけで保存キー・本文・日付を移動・上書きしない。

大きい２枠は現在の動く壁ルールのベストを表示する。現在の枠の保存方法、クリア直後・失敗・続行・終了の保存時期、ゲームの物理とルールは維持する。ルール変更以前のベストが新しい現ルールの結果に置き換わった意味ではない。

## 確認

合成した保存データで、現在25面／73面、迷路世代10面／16面、床世代107面を同時に置き、修正前の非表示を再現。回帰テストは修正前２失敗、修正後の関連４ファイル30件は成功した。

ローカルChromeの312／412／576幅で両難易度の６表示、再読み込み、現ルール80面への実保存を確認。旧107面は見え、旧保存本文は同一。空の保存先では記録を作らず、122資材・キャッシュ7da95b332c20edb1のオフライン表示も確認。ゲームのプレイ成績として107面を作った検証ではなく、保存データの読み取り・表示の確認である。
