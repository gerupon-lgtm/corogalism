## ラケットの役割

単独・道を開く組み合わせ・切り返しの組み合わせで、開始から傾き入力だけでラケットへ当て、水平へ戻した後も返球で次の区画へ進む例を確認。道を開く組み合わせの初配置は、返球をカップの側壁が邪魔したため、ラケット1枚を上側右端へ移した。静止壁・カップ・戻り道・入力は維持した。

一例の全コース所要時間は、単独で迂回15.712秒／返球15.936秒、切り返しの組み合わせで19.184秒／17.360秒、道を開く組み合わせで18.160秒／19.472秒。準備や狙い方も異なるため、全生成面で必ず速くなる根拠にはしない。返球の局所的な役割と、人間が楽しめる恩恵は分ける。[物理操作と軌跡](main-puzzles/benefit.json)、[再実行ツール](../../tools/verify-puzzle-racket-benefit.mjs)。
