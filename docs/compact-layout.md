# T-236 画面の高さ調整（v0.4.7）

添付スマホ画面のトップが見切れるため、元のトイ調と読みやすさを維持して余白を縮小。
- モードカードの余白とカード間隔を縮小。ガイド・設定は横並び、最低44pxの高さを維持。
- 枠外の操作説明フッタを整理し、トップ枠内に「© SIKUMI LAB」を配置。操作説明はタイトル・ガイド・プレイ中の案内を利用。
- 通常の記録を閉じたトップを393×820、390×780、360×800、320×720で1画面に収める。記録展開や長い通信通知、文字拡大時は必要に応じて自然なスクロールを許可。
- 設定・ラン結果も余白を縮小。設定は高さ約819px、短い画面では操作サイズを維持しスクロールで読む。
- 迷路・HUD・プレイボタンの位置と寸法は維持。ヘッダの統一サイズも維持。
