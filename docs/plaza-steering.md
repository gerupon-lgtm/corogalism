# T-283 広場での切り返し / v0.6.26

長い仕切りが1本だけだと、外周をL字に進む道が残る。床や壁の性質を使う前に抜けられるため、広場の生成を見直す。

## 本編の変更

- 広場の内側に2〜3本の仕切りを置き、通り道を奥・手前へ交互にずらす。単純なL字の近道を上下・左右とも遮り、途中で進行方向を切り返す構造にする。
- 仕切りの縦・横、本数、間隔、通り道の1〜2マス幅は種から決める。部屋は少なくとも2マス幅を残し、空いた場所の短い壁も全区画から抽選する。閉じた区画を作る追加壁は取り消し、最終的に全マスの到達性を確認する。
- 砂を使うテーマでは各空間へ砂の塊を分散。力場を使うテーマでは各空間へ選んだ向きを置く。休憩が選ばれた場合は置ける各空間へ足場を用意し、とりもちテーマでは各空間に複数配置する。他のテーマでの壁際とりもちの抽選も各空間へ広げる。
- 重力・反重力の強さと半径は維持。スタート・ゴールに加え、各出口の中央を力場の範囲から空ける。**以前の「1本の仕切りの出口側の帯を空ける」配置から、各出口の中央を保護する配置へ変更した。** 通り道の端や壁越しに力が届くことはある。
- 力場の印は短い内壁にも隠れない位置へ置く。同じ候補の確認結果を使い回し、配置を変えずに生成時の負荷を減らす。
- 取得物は完成した最短経路上へ置く。床やとりもちの追加配置で、ゴールへ成功する軌道を逆算しない。

2〜3本・1〜2マスは今回の本編の配置候補。検証全体の上限や、将来の候補を除外する条件ではない。7/8/9/11/13だけでなく15/17/21も確認対象に含める。

## 難しさとルール

壁は従来のゴムが主体。石・トゲ・こけのテーマも残し、素材の反発・ダメージ係数は変えない。壁を避けながらのクリア、反発で偶然ゴールを横切るクリアは引き続き認め、衝突回数をクリア条件にしない。

初期げんきは `40＋4×最終経路の曲がり角`。制限時間も完成した道の距離・曲がり角・床から従来の式で計算する。壁を増やす分だけ時間を手動で削る調整はしない。道が長くなることで、必要な時間とげんきも計算に反映される。

序盤8面の7×7、以降の大小・長短・広場の混在、後半を一律に難しくしない選び方は維持する。練習・チュートリアル・両おためしのコース、音、入力、通知の位置、開始・結果の待機、記録の区分は維持する。
