## 1. なぜHPを入れるか

フェーズ1完了時点の所見は**「十分遊べるが簡単すぎる」**だった。失敗の可能性が無いことが原因で、
難易度を上げる方向としては次の3つがある。

1. マスを細かくする → **却下**。実寸比較で操作精度の限界（7×7が下限、21×21は厳しい）を確認済みで、すぐ上限に当たる
2. 物理パラメータを速く・滑りやすくする → 操作感そのものが変わるため、慎重に扱う
3. **ぶつかることに代償を持たせる（HP）** → 盤面の粗さを7×7に保ったまま手応えを足せる

3を採用する。

## 2. HPを折れ回数でスケールする根拠

迷路は全セル連結のスパニングツリーなので、スタート→ゴールの経路は一意に決まる。
その経路上の方向転換の回数（以下「折れ回数」）は、生成時に決定的に計算できる。

**7×7の400シードでの実測:**

```
経路長（マス）: 最小13 / 四分位19〜31 / 中央値25 / 最大43
折れ回数      : 最小2  / 四分位11〜19 / 中央値15 / 最大32
```

**折れ回数と壁への衝突回数の相関は 1.000**（荒い操縦・60シード）。経路長との相関は0.906。
つまり**折れ回数は「その面で何回ぶつかることになるか」の予測値そのもの**であり、
経路長より直接的な指標である。HP予算を折れ回数でスケールする根拠はここにある。

これは構想たたき台の付録Aにある「制限時間は生成された迷路に依存するので難しい」という
指摘への回答でもある。**生成物の測れる性質でHP予算を正規化する**という同じ発想を、
実際に機能する指標で実行したもの。

## 3. ダメージの式（確定）

```
ダメージ = min(初期HP × 0.35,  10 × 素材のダメージ係数 × max(0, v − 1.2)²)
HP初期値 = 40 + 4 × 折れ回数
無敵時間 = 0.25 秒
```

`v` は衝突時の**法線方向の速度**（マス/s）。`physics/collision.js` の `onImpact(speed, wall)` が通知する。

HPの実例: 折れ2回→48 ／ 11回→84 ／ **15回→100** ／ 19回→116 ／ 32回→168。

### 閾値（1.2マス/s）が必須である理由

壁に傾きを入れ続けて押し付けると、**3秒で254回の微小接触**が発生する（速度の中央値0.10マス/s）。
閾値が無いと、これが全部ダメージになって一瞬でHPが溶ける。

```
閾値なし: 254回ダメージ（累計333）
閾値あり:   2回ダメージ（累計175）
```

**閾値は「連打の防止」と「丁寧な操作が報われること」を同時に満たす。** そっと当てれば無傷になるので、
フェーズ0の合格ラインbで最重要とした「狙った隙間で止められる」操作が、そのまま有利になる。

なお、**反発による連打は起きない**（当初の懸念は外れだった）。跳ね返った直後は壁から離れる方向に
動くため即座に再接触しない。実測した接触の間隔は中央値0.40秒で、これは曲がり角ごとの別々の衝突。

### 1発の上限（初期HPの35%）が必須である理由

経路追従の自動操縦では衝突速度の最大は2.46マス/sだが、**壁に全力で突っ込むと5.38マス/s**まで出る。
上限が無いと `10 × (5.38 − 1.2)² = 175` となり、**初期HP100の面で1発即死**する。

上限は**全力衝突だけを抑え、角での擦り傷ダメージには影響しない**（角の衝突は上限に届かない）。
そのため後述の難易度勾配は上限を付けても保たれる。

## 4. 検証データ（自動操縦・200シード）

「操縦の荒さ」は経路追従の目標速度で、腕前の代理指標。

| 操縦の荒さ | 生存率 | 折れ回数別の生存率 |
|---|---|---|
| 3.5（丁寧） | 100% | 少100% / 中100% / 多100% |
| 4.5 | 100% | 少100% / 中100% / 多100% |
| 4.8 | 100% | 少100% / 中100% / 多100% |
| **5.0（雑）** | **51%** | **少91% / 中44% / 多26%** |
| 5.2 | 11% | ー |
| 5.5 | 4% | ー |

少=折れ10回以下、中=11〜19回、多=20回以上。

**読み取れること:**

- **丁寧に走れば、折れ回数がいくつでも生存率100%。** HPは「雑さ」を罰する仕組みで、
  「複雑さ」自体は罰していない。複雑な面は**丁寧さの要求が上がる**形になる。
  これが「無理ゲーにならないレベルで難易度の平坦化を避ける」の実装
- 雑に走ると、複雑な面ほど落ちる（91% → 44% → 26%）。平坦化していない

### この数値の限界（重要）

- **機械の操縦による測定**であり、自動操縦の衝突速度は1.5〜2.5に固まっている。
  そのため生存率が4.8→5.2で急に落ちる階段状になっている。**人間のプレイはばらつくので、
  実際はもっと緩やかな曲線になる**
- したがってこれは**出発点であって確定した balance ではない**。試遊して調整する前提

検証に使ったコードは `tools/` に置いてある（`tools/hp3.mjs` が上の表を出す）。
数値を変えたらこれを回して、生存率と勾配がどう動くか確認できる。

## 5. 壁の素材

反発係数とダメージ係数を**別々に振れる**ことがこの設計の面白いところ。

| 素材 | `restitutionK` | `damageK` | 手触り |
|---|---|---|---|
| `default` | 1.0 | 1.0 | 基準 |
| `rubber`（ゴム） | 1.5 | 0.4 | よく跳ねるが痛くない。リカバリーしやすい |
| `stone`（石） | 0.7 | 1.4 | 跳ねずに止まるが痛い |
| `spike`（金属・棘） | 1.2 | 2.0 | 跳ねて痛い。近寄りたくない壁 |
| `moss`（苔） | 0.5 | 0.2 | 安全地帯。逃げ場として置ける |

**「よく跳ねるが痛くない壁」と「跳ねないが痛い壁」が別物になるので、壁そのものがギミックになる。**

上の数値は【想定】の出発点。`materials.js` にデータとして足すだけで効く（物理コードは触らない）。

床の素材（摩擦を変える氷・砂など）とは別の軸として扱う。壁は `damageK` と `restitutionK`、
床は `frictionK` と `accelK` が主に効く。同じ `MATERIALS` テーブルに置き、使われ方で決まる。

## 6. 実装の要点

- ダメージは `physics/collision.js` の `onImpact(speed, wall)` を使う。**衝突判定を二重に持たない**
- 素材のダメージ係数は `resolveParams` と同じ考え方で解決する（壁の `materialId` から引く）
- HPの状態管理は `src/game/hp.js`（新規）に閉じ込め、物理コードにHPの概念を持ち込まない
- 折れ回数は `src/maze/path.js`（新規）で算出し、`MazeGraph` に `turns` として持たせる。
  **この計算は後続2作（迷路脱出ゲーム / AmazingMaze）でも使えるので、独立モジュールにする**

## 7. 【要確認】

以下はHP単体検討時の記録。HP0とスコアの現行仕様は `run-and-score.md` §9が優先する。
v0.2.0ではHP0・時間切れでS-106へ進み、2回までコンティニュー可能。
残HPはクリア時の評価表示、主スコアはクリア面数、副スコアは合計クリアタイム。

- **HPが0になったときの扱い**: 【想定】その面をやり直す（タイムは記録しない）。
  ゲームオーバー画面を別に作るか、クリア画面を流用するか
- **残HPをスコアにするか**: 【想定】クリア時に残HPをボーナスとして表示する。
  タイムアタックとの関係（どちらを主指標にするか）は要判断
- **折れ回数をプレイヤーに見せるか**: 【想定】見せない（HPバーだけ）。面ごとにHPが違う理由が
  伝わらない懸念はあるが、数字を出すと攻略情報になりすぎる
- **操作モード間の公平性**: 擬似傾きモードは速度の出し方が違うため、HPの減り方も変わる。
  記録を分けるかどうかはフェーズ1からの継続課題

## 8. v0.2.0の素材描画

標準は薄緑のダッシュ、ゴムは青緑の気泡、石は灰褐色の目地、棘は赤のジグザグ、苔は緑の斑点。
模様を壁の矩形内にクリップし、描画上の突起で当たり判定を誤認させない。
外周は標準。従来の検証済み配置を維持しているため、ゴムは定義・描画対応のみで現在は出現しない。

## 9. v0.2.1の序盤補正

試遊の「時間不足・HPがすぐ減る」を受け、1面目の通常ダメージを半分、単発上限を初期HPの20%に緩和。
10面目で通常の倍率・上限35%へ滑らかに戻す。式と具体例は `run-and-score.md` §10。
`createHp` の任意引数 `damageCapRatio` が面ごとの上限を受け取り、`cfg.capRatio` の35%を超えないよう制限する。
閾値1.2マス/s、無敵時間0.25秒、初期HPの式は変更しない。
