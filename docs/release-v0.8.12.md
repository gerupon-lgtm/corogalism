# v0.8.12 設定画面の高さと見出し

2026-10-25、T-306。非全画面で操作の設定画面が縦にスクロールする報告と、タイトル周りをトップへ揃える依頼への対応。

## 原因の再現

修正前の実ブラウザで、幅360〜393px・高さ700〜780pxでは82〜162px、上下余白を模擬した390×844では60pxはみ出した。設定を終えるボタンまでが見えても、その下の端末・オフラインの案内を含むページ全体は収まっていなかった。以前のcompact-layout検証は設定画面の高さをログへ出すだけで、スクロール0の判定がなかった。

393×740で、ページの最小高さを解除しても122pxの超過は変わらず、下の余白をなくしても110px超過。操作モードを横並びにすると84pxへ減った。余白の二重加算だけではなく、項目と案内の縦積みが主因だった。

## 変更

- 見出しはトップと同じ26px、小物はキャンディと砂時計。コルク壁を添え、英字の小見出しは置き換える。
- 操作モードを横並びにし、「擬似傾き（押した位置）」を「押した位置で操作」へ変更する。機能は同じ。
- 音量は項目・スライダー・数値の一列とし、ボタンの押せる高さやスライダーの操作高さは維持する。
- 全画面とオフラインの補足は「全画面・オフラインの案内」で開閉する。説明は削除しない。全画面ボタンを押したときは案内を自動で開き、成功や非対応の結果を見せる。
- 基準の再設定・設定を終える・縦向きで全画面は44px以上。ゲーム中から開く際に追加される案内も考慮して項目間の余白を調整する。

ページのスクロールを一律に禁止する処理は使わない。補足を自分で開いた場合や、さらに小さな表示領域・大きな文字設定では、内容を読めるよう自然なスクロールを残す。本編の物理・記録・BGMは変更しない。表示・資材URLとprecacheは0.8.12へ更新する。
