# v0.8.0：おもちゃ箱のトップと5系統のBGM

T-294 / 2026-10-24。ユーザーがトップ画面案home-candy-r16、キャンディの輪郭、採用BGM bgm-levels-r6を本編へ反映し、ブラウザ検証後の公開まで進めることを承認。版はユーザー指定の0.8.0。

## 画面

承認済みの木箱の形・黄／桜／若草の配色・白木背景・26pxの「どう遊ぶ？」を採用。66pxの練習入口、44px以上の操作、50pxの開始ボタン。押下中は積み木が3px沈む。飾りは本編と同じボール・葉っぱ・ゴール・キャンディ・砂時計を一度描く。キャンディのトップ装飾は49→67に拡大。

「動く壁のあそび方」「床の練習」はトップから非表示にする。機能を削除したり、試遊ページの候補・物理を制限したりしない。基本チュートリアルに続く動く壁の紹介は従来どおり。自己ベストの折り畳み、現行・旧3世代の記録表示、難易度の保存、ガイド・設定・明示的な更新確認を維持。保存キー・ルール世代・迷路・げんき・制限時間は変更しない。カメラ回避用の上余白と、文字拡大時の自然なスクロールを保つ。

## キャンディ

本編・ガイド・タイトルが共用する描画で、包み紙と中央の楕円に細い茶色 #75644f の輪郭を加える。線幅は描画座標で max(0.043×size, 0.7px)。キャンディの模様・反射・浮遊・本編でのサイズ・回復量・取得判定は維持。ゲーム内のキャンディを拡大して当たり判定とずらすことはしない。

床への接触ごとに曲を変えず、面を読み込んだときの主役で選択。やさしい・通常に同じ方針を使い、動く壁のある面は床・壁の素材より優先。練習・基本チュートリアルは現行曲、動く壁の紹介では冒頭曲。

READY・カウントダウン・ポーズ・結果・非表示中はBGMを鳴らさない。スタート音0.8秒＋間0.2秒の後に曲の先頭から再生。各WAVをそのままループし、開始・停止は0.14秒で音量を変化させる。面間は既存のクリアジングルと準備の間を保つ。追加曲は必要な面で取得し、読み込みを待ってゲームを止めない。遅れて届いた前の曲や、停止中に届いた曲を勝手に再生しない。失敗した曲は音OFF→ONの再試行対象。
