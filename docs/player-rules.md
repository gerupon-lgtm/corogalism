v0.8.3では葉っぱを取れない理由の表示を追加しました。取得条件や効果はv0.8.2から変えていません。

## げんきと、葉っぱのまもりは別のもの

**げんきは残りの体力、葉っぱのまもりはダメージを先に引き受ける蓄え**です。げんきが満タンでも、まもりに空きがあれば葉っぱを取れます。

| 項目 | ルール |
| --- | --- |
| げんき | 壁の素材と衝突の強さに応じて減る。チャレンジでは0になると失敗 |
| その面の最大げんき | 道の曲がる回数で決まるため、面ごとに変わる |
| 葉っぱのまもり | まずまもりが減り、足りない分だけげんきが減る。げんきそのものは回復しない |
| ノーミス扱い | まもりだけで防いで、げんきが一度も減らなければ対象。減った後に回復してもノーミスには戻らない |

## アイテムを取れる条件

| 対象 | 効果 | 取れないとき |
| --- | --- | --- |
| キャンディ | その面の最大げんきの20%を回復。満タンを超えない | **げんきが満タン**。キャンディは消えずに残る |
| 葉っぱ | その面の最大げんきの20%分をまもりへ追加。追加できるのは最大げんきの50%まで | **まもりが、その面の最大げんきの50%以上**。葉っぱは消えずに残る |
| 砂時計 | のこりじかんを5秒追加 | チャレンジで時間切れ・げんき切れが成立した後は取れない |

葉っぱは上限までの空きが少なくても取れます。その場合、空いている分だけ増えて葉っぱは消えます。満タンで残ったキャンディや葉っぱは、それぞれに空きができれば取れます。

取れない状態で触れると、盤面の外に「げんきはまんたん！」「葉っぱのまもりはまんたん！」と理由を表示します。触れ続けている間は繰り返さず、離れて戻ると再び表示します。

**例：最大げんき100の面**では、キャンディの回復量は最大20、葉っぱの追加量は最大20、まもりの追加上限は50です。げんき100・まもり40でも葉っぱを取れて、まもり50になります。まもり50では、げんきが減っていても葉っぱを取れません。

> **面をまたぐときの注意**：まもりの残量はそのまま持ち越します。次の面の上限より多くても切り捨てません。その面の上限未満までまもりが減ると、また葉っぱを取れます。上限は「追加できるかの基準」です。

## 床と時間

| 対象 | ルール |
| --- | --- |
| ひとやすみ | げんきが減っているとき、床の上で2秒ほぼ静止すると最大げんきの20%を回復し、のこりじかんを2秒追加。満タンなら未使用のまま |
| ひとやすみの回数 | **床1枚につき1回**。同じ面に複数あれば別々に使える。移動・ポーズなどで途中の進み具合はリセット |
| とりもち | 乗ると止まり、自然に3秒で脱出。盤面内のダブルタップ1組で拘束時間を0.5秒短縮、最短0.5秒。対応端末では本体への軽いトントンでも短縮できる |
| とりもちの再接触 | 脱出後、その床から完全に離れるまでは再び捕まらない |
| のこりじかん | ひとやすみ中・とりもち中も減る。砂時計や休憩の加算分は、その面だけで有効 |
| 失敗とゴールの順序 | 同じ瞬間に起きた場合は、げんき切れ・時間切れがアイテム取得、休憩成立、ゴールより優先 |

時間を増やしても、記録のクリアタイムからは差し引きません。アイテムや床の有無・配置は面によって変わり、毎面すべてが出るわけではありません。

## 次の面・コンティニューでどうなるか

| 状況 | げんき・時間 | 葉っぱのまもりと取得・使用状態 |
| --- | --- | --- |
| 次の面へ | 新しい面の最大げんき・制限時間で開始 | まもりの残量を維持。アイテムと床は新しい面のものになる |
| コンティニュー | 失敗した同じ面を最初から。げんきは満タン、時間と追加時間をリセット | まもりの残量を維持。取った葉っぱ・使ったひとやすみは復活しない。キャンディと砂時計は同じ位置へ復活 |
| 新しいチャレンジ | 1面目から開始。コンティニューは1回のチャレンジにつき2回 | まもりは0から。前のチャレンジの取得・使用状態は引き継がない |

## 遊び方による違い

| 遊び方 | 失敗条件など |
| --- | --- |
| チュートリアル（基本紹介・動く壁の紹介） | 時間制限なし。げんきは減るが、0でも操作・クリア・0からの回復ができる。チャレンジ記録には入らない |
| プラクティス | 通常床・通常壁の7×7を5面。げんき・時間制限・アイテム・特殊床なし。同じ面の再挑戦は面数を進めない |
| 床の練習 | げんき・時間制限なしで床を切り替えて試す。現在はトップの入口を非表示にしている |
| チャレンジ「やさしい」 | 「通常」より衝突ダメージが小さく、時間に余裕があり、回復アイテムなども出やすい。げんき0・時間切れで失敗 |
| チャレンジ「通常」 | やさしいより厳しい設定。げんき0・時間切れで失敗。記録は難易度別・コンティニュー使用有無別に保存 |

「やすらぎ」という面名でも、大きさや道の長さは面によって変わります。序盤の13×13やすらぎの厳しさは現在観察中で、この整理に合わせた難易度変更はしていません。
