## 依頼と実装

2026-09-12の追加指示。現行C案のトイ調を維持する。

- タイトル見出しは「今日はどちらで遊ぶ？」（読点なし）。
- 追記指示により、モード選択のカウントダウン説明を削除。開始時の3カウント自体は維持。
- プラクティスの説明は句点で2つの文に分割。幅が足りないときは文単位で2段にし、余裕があれば1行。
- 下部の葉ロゴを削除。ヘッダの葉・Corogalism文字は維持。
- 追記指示により、コピーはロゴ右に「A SMALL MAZE」「A BIG FEELING」の2段で配置。
  v0.2.4ではバージョンは開発中注記の右（v0.2.5でロゴ行へ変更）。320px幅でもロゴとコピーを横並びにする。
- 記録は独立した明るいクリーム色のカード2枚。「自己ベスト」の見出し、濃いラベル、
  大きいクリア面数、小さい合計タイム。未記録は「これから挑戦」。保存キー・計算・順位は維持。
- プレイ下部の「基準をとり直す」「設定」は丸い成形ボタンと面取り・押し込みを統一。
- 設定は専用のクリーム色カード。選択中の入力モードは緑色＋チェック、角度は大きい数値、完了はオレンジ。
  タイトル・プレイ・クリア・ゲームオーバーのどこから開いても迷路・HUD・ポーズ・操作説明を非表示。
  開くと先頭へスクロールし、閉じると元の位置を復元する。
  プレイの進行を止め、戻っても手動再開＋3カウント。クリア・ゲームオーバーからは元の結果に戻す。
- ロゴ以外はGoogle FontsのM PLUS 1p。Kosugiは400のみで、太字見出し・数値に不足するため代案を採用。
  Regular/Bold/BlackをWOFF2で同梱。中間ウェイトは近い配布ウェイトを選択。
  `font-display:swap`と日本語OSフォントのフォールバック。外部サービスへの実行時アクセスなし。
  出典・ライセンスは `assets/fonts/README.md` / `OFL.txt`。
- 壁幅を0.10→0.24セル（2.4倍）。描画と当たり判定を同じ矩形に保つ。
  素材アトラスは維持し、太い面により溝・石・苔・三角の意匠を見せる。
  上辺ハイライト、下辺陰影、標準／棘／ゴムの丸い端部でC案の成形パーツへ近づける。
  ゴムは引き続き定義・描画のみで実ステージには未配置。
