# v0.8.11 結果カードの間隔と記録区分

2026-10-25、T-305。ユーザーの配置画像と追加指定に合わせ、結果のクリア面数を見出し側にまとめ、合計クリアタイム・ノーミスを独立した行へ分ける。「クリア面数の下端→合計タイムの上端」と「合計タイムの下端→自己ベストの上端」は同じ間隔にする。外枠内の余った高さを均等に配分し、自己ベストだけの1pxの上余白は除去する。

「やさしい・ノーコンティニューの記録」などの区分表示は12pxから14px、太字700へ変更。区分とクリア面数の間は通常16px、短い画面は8pxとし、操作ボタンは縮めない。ゲーム・物理・記録保存・BGM・トップは変更しない。表示と資材URL、precacheは0.8.11へ更新する。
