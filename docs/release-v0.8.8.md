# v0.8.8 見出しの壁飾りと短いチュートリアル

2026-10-25、T-302。ユーザーのv0.8.7スクリーンショットに対する調整。

トップの「どれで遊ぶ？」の下に、本編と共用の描画によるコルク壁のラインを置く。内側の幅の72%とし、左右に余白を残す。ラン結果はボール・タイトル・ゴールを一列にし、同じ壁ラインと記録区分を一まとまりにする。高い画面で見出しと区分の間だけが広がらない構成へ変更する。短い画面はボタンの大きさを維持して部品間の余白を調整する。

## チュートリアル

トップからのチュートリアルは合計3面にする。

1. 従来の基本素材・アイテム・床の説明面。
2. ラケットの中心と端で打ち返す面。
3. 動く壁を順に動かして道を開く面。

動く壁の紹介は6面から2面へ短縮。いずれも通常床・通常固定壁、時間制限なし。げんきは減るが0でも続けられる。途中のリトライは同じ面、最後の「モード選択へ」で終了する。省いた切り返し・組み合わせは同じ傾き操作の応用で、本編の出現候補は維持する。とりもちはタップで脱出を早める別操作があり、最初の説明面に残す。

本編の物理式・素材候補・記録・BGMと、5面のプラクティスは変更しない。表示・URL・precacheを0.8.8へ更新する。
