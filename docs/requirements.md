# フェーズ2（HPと壁の素材）

**背景**: フェーズ1完了時点で「十分遊べるが簡単すぎる」。ぶつかることに代償を持たせて手応えを足す。
数値の根拠・検証データ・素材テーブルは `docs/hp-and-materials.md` が正典。

## 10. 折れ回数

| ID | 機能 | 内容 | 必須度 |
|----|------|------|--------|
| F-201 | 経路の算出 | スタート→ゴールの一意な経路を求める。**後続2作でも使える独立モジュールとして書く**（`maze/path.js`） | 必須 |
| F-202 | 折れ回数の算出 | 経路上の方向転換の回数を数える。`MazeGraph` に `turns` と `pathLength` として持たせる | 必須 |

折れ回数と壁への衝突回数の相関は 1.000（実測）。HP予算のスケール根拠。

## 11. HP

| ID | 機能 | 内容 | 必須度 |
|----|------|------|--------|
| F-211 | HP初期値 | `40 + 4 × 折れ回数`。折れ15回の標準的な面でちょうど100 | 必須 |
| F-212 | 衝突ダメージ | `10 × 素材のダメージ係数 × max(0, v − 1.2)²`。`v` は法線方向の速度（マス/s） | 必須 |
| F-213 | **ダメージ閾値** | 1.2マス/s以下の接触は無傷。**壁への押し付けで3秒に254回発生する微小接触を無効化するために必須**（`docs/hp-and-materials.md` §3） | 必須 |
| F-214 | **1発の上限** | 1回の衝突で失うHPは最大35%。v0.2.1では1面目20%から10面目35%へ段階的に上げる。**単発上限の仕組みを維持する** | 必須 |
| F-215 | 無敵時間 | ダメージ発生後0.25秒はダメージを受けない | 必須 |
| F-216 | HP表示 | ゲーム画面にHPバーを表示する。減ったことが分かる見せ方にする | 必須 |
| F-217 | HP0の扱い | **ランが終わる**（F-243）。ゲームオーバー画面 S-106 でコンティニューを選べる。面のやり直しではない | 必須 |
| F-218 | 残HPのボーナス | 【想定】クリア時に残HPを表示し、ボーナスとして扱う | 推奨 |

**設計の性質（これが要件の意図）**: 丁寧に走れば折れ回数がいくつでも生存率100%。
**HPは「雑さ」を罰する仕組みで、「複雑さ」自体は罰さない。** 複雑な面は丁寧さの要求が上がる形になる。
これが「無理ゲーにならないレベルで難易度の平坦化を避ける」の実装。

## 12. 壁の素材

| ID | 機能 | 内容 | 必須度 |
|----|------|------|--------|
| F-221 | 壁のダメージ係数 | 壁の `materialId` から `damageK` を引いてダメージに掛ける | 必須 |
| F-222 | 素材の定義 | `default` / `rubber` / `stone` / `spike` / `moss` を `materials.js` にデータとして足す | 必須 |
| F-223 | 素材の配置 | 生成後の迷路に壁素材を配置する。配置ルールは【要確認】 | 必須 |
| F-224 | 素材の描画 | 素材ごとに見分けがつく描画。**見えないと理不尽になる** | 必須 |

反発係数とダメージ係数を別々に振ることで、「よく跳ねるが痛くない壁」と「跳ねないが痛い壁」が
別物になる。**壁そのものがギミックになる。**

## 13. フェーズ2の判断ポイント

実装完了後、発案者が実機で評価する: **「単調さが解消したか」**と**「無理ゲーになっていないか」**。

合わせて回帰確認: 丁寧な操縦で死なないこと（自動操縦テストで機械的に検証する。F-2xx の安全性の要）。

## 14. モード構成とラン（器の部分）

`docs/run-and-score.md` が正典。**HP0で失うものが無いとゲームオーバーが痛くない**ため、
HPとラン構造はセットで入れる。

| ID | 機能 | 内容 | 必須度 |
|----|------|------|--------|
| F-231 | モード選択 | チャレンジ／プラクティスを選べる | 必須 |
| F-232 | チャレンジモード | HPあり。ランシードから面を連続生成し、難易度が上がる。主指標は到達面数 | 必須 |
| F-233 | プラクティスモード | **HPなし**。シード指定の1面。主指標はクリアタイム。フェーズ1の実装をそのまま使う | 必須 |
| F-241 | ランシードの導出 | ラン全体を1つの `runSeed` から導出する。**ラン全体が再現でき、同じランを他人と競える** | 必須 |
| F-242 | HPの面ごとリセット | 各面の開始時に `40 + HP係数 × 折れ回数` で再計算する。**持ち越さない** | 必須 |
| F-243 | ゲームオーバー | HP0でランが終わる。失うのは積み上げた到達面数 | 必須 |
| F-244 | コンティニュー | 1ランに2回まで【想定】。失敗した面からHP満タンで再開し、到達面数は維持する | 必須 |
| F-245 | 記録の分離 | **ノーコンティニュー到達面数**と、コンティニュー込み到達面数を別々に保存する | 必須 |
| F-246 | スコア | 主=到達面数、副=合計タイム。ノーミス面数は【想定】あれば | 必須 |
| F-247 | **制限時間** | `経路長 × 1マスあたりの秒数(面数)`。v0.2.1では1面目に2.5倍の余裕を持たせ、10面目で従来値に戻す。**経路長で正規化する原則を維持する** | 必須 |
| F-248 | 時間切れ | 制限時間を過ぎたら、HP0と同じくランが終わる | 必須 |
| F-249 | 残り時間の表示 | 残り時間が分かる表示。**時間が主要な圧力なので見せ方が体験を左右する** | 必須 |
| F-251 | 難易度カーブ | **1マスあたりの秒数を削るのが主レバー。** 加えて `spike`/`stone` の比率が上がり、`moss` が減り、HP係数が下がる | 必須 |
| F-252 | **マスは7×7固定** | 難易度をマスの細かさで上げない。**サイズを上げると折れ回数が増えてHPも増え、平坦化が戻るため** | 必須 |

**F-247（制限時間）が必須な理由**: HPだけでは終わりが来ない。閾値以下の接触は無傷なので、
壁に当てない走り方をする限りHPは減らず、実測では**丁寧なプレイで永遠にランが続いた**
（`docs/run-and-score.md` §5）。**時間が「丁寧に走っても避けられない圧力」を作り、
HPがその圧力下でのミスを罰する。** 時間切れとHP0が両側から挟むので、
速すぎても遅すぎても終わり、プレイヤーは自分で最適点を探すことになる。

**F-245（記録の分離）の意図**: コンティニューで先に進んで新しい面を見る楽しみと、
ノーコンで記録を狙う緊張が、互いを壊さずに両立する。フェーズ3のスター評価の軸にも繋がる。

## 15. フェーズ2の【要確認】

- 折れ回数をプレイヤーに見せるか（【想定】見せない）
- 壁素材の配置ルール（【想定】まずはシードから決定的にランダム）
- 床素材（氷・砂などの摩擦系）を同じフェーズでやるか、次に回すか
- コンティニューの回数（【想定】2回）
- ノーミス面数を入れるか

- 残り時間の見せ方（バー／数字／両方）。**時間が主要な圧力になったので体験を左右する**
