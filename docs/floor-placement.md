# T-272 床は脇道にも、取得アイテムはルート上へ / v0.6.14

床をゴールへの道だけに置くと、模様が正解ルートの目印になります。体験しやすいルート上の配置は残し、通らなくてもよい脇道にも同じ性質の床を置き、盤面全体の見た目を自然にする変更です。

ここでいうルートは、迷路を加工した後に求めるスタートからゴールへの最短経路です。広い通路の面などでは、ほかの行き方もできます。

## 変更前に確認した配置

- 氷はすでに盤面全体を覆い、砂のあるマスだけ除いていた。
- 砂・重力・反重力の配置場所とひとやすみは、主に最短ルート上だった。力場は壁越しに届くため、効果そのものは脇道にも及んでいた。
- とりもちは初登場11面がルート上の1枚、後半は脇道に2枚目を置く構成だった。
- 自動生成面のキャンディ・葉っぱ・砂時計はルート上。固定チュートリアルのキャンディと葉っぱは最短ルート外だった。

## 現行の配置

| 対象 | 配置のしかた |
|---|---|
| 氷 | 従来の全面配置を維持。砂との重複を避ける |
| 砂 | ルートの減速区間を残し、脇道にも短い砂のまとまりを2箇所追加。隣接マスへ広げるときは間の壁を越えない |
| 重力・反重力 | 従来のルート上の力場を残す。その面で使う引く／押す力それぞれについて、脇道へ1箇所ずつ追加できる空きを探す |
| ひとやすみ | 従来の出現抽選とルート上の1枚を維持し、出現する面では脇道にも1枚追加できる場所を探す |
| とりもち | 初登場から、ルート上の1枚に加えて脇道にも1枚を置ける場所を探す |
| キャンディ・葉っぱ・砂時計 | ルート上に配置。床やしかけとの重複を避け、取得物は力場の中心付近を避ける |

砂のまとまりは空きマスが少なければ小さくなる。スタート・ゴール付近は新しい脇道配置から離し、ルート上の配置を脇道へ移してしまうことはしない。同じシードと面・難易度なら、コンティニューでも同じ配置になる。

力場はルートから離れた場所を優先するが、壁越しにルートへ届く場合がある。追加した力を見た目だけにしたり、脇道だからと弱めたりはしない。やさしい初登場の既存力場同士の間隔は維持する一方、脇道への追加分は既存の配置間隔を使い、影響範囲が重なる場合もある。追加分も従来の時間計算に含め、時間を短くしない。

ひとやすみは静止が必要なため、氷上や力場の届く範囲を避ける。止まれる空きがない面では追加しない。これは本編の配置条件であり、検証ページの素材や組み合わせを候補から除く判断ではない。

固定チュートリアルは、キャンディを(3.5,1.5)、葉っぱを(1.5,3.5)へ移して最短ルート上にそろえた。葉っぱは氷の体験と重ならない、とげ付近の曲がり角へ置く。砂時計は元からルート上。床・壁・しかけ・15要素の体験構成は維持する。タイトル内の床の練習と別ページの素材検証は、同条件を比較する配置を維持する。

## ひとやすみを複数使う処理

従来の`stage.rest`を1枚目として残し、追加分を`stage.extraRests`に保持する。`restFloors(stage)`が両方を返し、描画・静止判定・回復・案内・ポーズ時のリセットに同じ一覧を使う。

進み具合と使用済み状態は床ごとに独立する。別の床へ移動したときやポーズしたときは、途中の静止時間をリセットする。コンティニュー時は使った床の座標を`restUsedCells`として渡し、同じ床が復活しないようにする。回復量や必要な静止時間は従来どおり。
