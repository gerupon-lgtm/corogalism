# コロガリズム / Corogalism — LP掲載用の概要資料

作成・更新日：2026-10-07 ｜ 対象：v0.6.21 ｜ 制作：シクミラボ / SIKUMI LAB

傾きで加わる力に、すでに転がっている勢い、床の滑り、壁の反発が重なることで、同じ操作でも動きが変わります。コロガリズムは、その違いを迷路の楽しさにつなげるブラウザゲームです。

本資料は現行コードと仕様資料を照合した概要です。動作確認の範囲と公開状況は末尾の検証記録を根拠としています。以下では「本編で遊べるもの」「別ページで検証中のもの」「未実装の候補」を区別します。

## 1. 現在地

v0.6.20で、やさしいモードで107面まで進んだ試遊を受け、大小の迷路・入り組んだ道・素直な道・反発の広場を混ぜ続ける構成を追加しました。後半ほど難しいという固定順にせず、直近の体験を見て変化をつけます。既存の時間・げんきの計算と素材の性質を維持し、球描画も軽量化しました。公開画面で見つかった長い面名の重なりもv0.6.21で修正しています。185テスト・公開実pointer48面クリアに加え、最終版の描画復元100条件・3幅・本編の入力と音・オフライン・109資材一致を確認して公開済みです。実端末の長時間の面白さと負荷は追加試遊の対象です。[最新の確認範囲](verification/maze-variation.md)。次面の待機1秒＋色の復帰0.3秒、終了前の確認も維持しています。

本編のボールは現在ビー玉です。金属・木・スーパーボール・スポンジは検証ページで試せます。本編での選択機能や、面ごとに素材を変える仕組みは未実装です。

## 2. LPに使える紹介文

### メインコピー

**すべって、はずんで、迷路を抜ける。**

### ゲームの紹介

スマホを傾け、ビー玉を迷路のゴールへ。滑り続ける氷、ブレーキになる砂、軌道を曲げる重力と反重力。小さな迷路、大きな迷路、反発の広場を行き来しながら、道と勢いを読むブラウザゲームです。時間を気にせず試す練習から、連続クリアに挑むチャレンジまで、自分のペースで遊べます。

### 素材検証の紹介

重い金属がじわっと動き、スーパーボールが大きくはずむ。木が壁に当たれば、乾いた「コン」。別のおためしページでは、ボール・床・壁を切り替えて、動きと音の違いを試せます。素材の個性を組み合わせながら、新しい遊び方を探しています。

### 操作と開発状況の短い案内

スマートフォンの傾き、または画面のタッチ・クリックで遊べます。現在は公開試遊中の開発版です。

## 3. 本編の楽しさと遊び方

### 傾きだけでは決まらない、転がる手触り

勢いがついたビー玉は、傾きを戻してもすぐには止まりません。早めに逆へ傾けて減速したり、砂の上で立て直したり、壁の反発を利用したり。迷路の道順に加えて「どう転がすか」を考える楽しさがあります。

### 固定しない迷路と、段階的に出会う素材

チャレンジの迷路はプログラムで生成し、ゴールへの道があることを確認します。最初は順番に床へ出会い、その後は直近の大きさ・形・素材との違いを考慮して抽選します。7×7・8×8・9×9・11×11・13×13が入り交じり、同じ7×7にも長い道と短い道があります。これを採用上限とは説明せず、さらに大きな盤面も検証対象に残します。砂や力場、ひとやすみ・とりもちは脇道にも置き、取得アイテムはゴールへのルート上に配置します。

反発の広場は基本壁をゴムとし、選ばれた石・トゲ・こけも残します。一度の一定傾きで無衝突のままゴールへ直行する道を遮り、壁の反発や傾きの修正で狙う遊びを作ります。偶然の通過ゴールも認めます。ボールの素材と綿の吸収壁などは、この本編追加とは別の検証・将来候補です。

序盤は基本操作から始まり、3面で砂、4面で全面氷＋ゴム壁、5面で重力、7面で反重力に出会います。氷＋砂、氷＋力場の複合面にも段階的に進みます。

### 自分のペースで入れる入口

| 遊び方 | 内容 |
|---|---|
| はじめてのあそび方 | 持ち方から案内。壁・床・しかけ・アイテムの15要素を、一つの練習面で体験。時間制限・ゲームオーバーなし |
| プラクティス | げんき消費・時間制限なし。同じ迷路を繰り返し、クリアタイムを縮める |
| 床の練習 | 同じ広い面で普通・砂・氷・重力・反重力を切り替える。げんき消費・時間制限・記録なし |
| チャレンジ | 「やさしい」「通常」の2段階。げんきと残り時間を使い、何面クリアできるかに挑む。自己ベストを端末に保存 |

通常・やさしいの両方で難易度を緩和済みです。やさしいは経路の長さ、曲がり角、砂や力場の負担に合わせて時間を確保します。新しい素材の説明はプレイを止めず、短い案内で伝えます。

通常では10面ごとに、広いカーブと複数の素材を使う特別面「光の滑走路」が登場します。専用ジングルとゴールの光を用意しています。やさしいの結果画面には条件に応じて控えめな予告を表示し、切り替えを迫る画面は出しません。

### 見た目と音

木のおもちゃを思わせる迷路、つやのあるビー玉、素材の色や模様で、見た目からも違いを伝えます。あそびのガイドには「すべる・曲がる・軌道が変わる」の絵と、壁・アイテム・床の説明を掲載。BGM、効果音、短い紹介ジングル、音の切り替えも実装しています。

## 4. 本編に入っている床・壁・しかけ

### 床：勢いと進路を変える

| 床 | 今の遊びへの効き方 |
|---|---|
| 普通 | 基準になる転がり方 |
| 氷 | 勢いが長く残る。早めの減速や、大きく曲がる操作を楽しむ |
| 砂 | 勢いを落とす。氷からの減速や曲がり角の手前で立て直す |
| 重力 | 近くの中心へ引く。近づく向きによって軌道や速さが変わる |
| 反重力 | 中心から外へ押す。近づくと押し戻され、抜けるときには勢いがつくことがある |

全面氷＋全面ゴム壁、氷＋砂、氷＋重力・反重力は本編に採用済みです。重力・反重力は内向き／外向きの粒子や矢印で表し、影響範囲の外周を囲む境界線は描いていません。

### 壁：反発とげんきの減り方が違う

| 壁 | 本編での特徴 |
|---|---|
| 標準 | 基準となる反発とダメージ |
| ゴム | よくはねる。ゴム壁への衝突自体ではげんきが減らない |
| コルク | ほどよくはねる。ダメージが小さく、床の動きを楽しむ面に使う |
| 石 | はねにくく、ダメージが大きめ |
| とげ | 大きなダメージを受ける危険な壁 |
| こけ | はねにくく、ダメージが小さい |

チャレンジでは、ぶつかる強さと壁素材でげんきの減り方が変わります。ゴムで反発した先の別素材の壁では、そちらのダメージが発生します。床主体の面は主にコルクを使い、全面氷＋ゴムの面とは性格を分けています。

### 立て直しと、ひと工夫のしかけ

- **キャンディ**：げんきを20％回復。満タンのときは取らずに残せる。
- **葉っぱのまもり**：ダメージを肩代わりする。
- **砂時計**：残り時間を5秒増やす。
- **ひとやすみ**：2秒じっとすると、げんき回復と残り時間の追加。
- **とりもち**：しばらく動きにくくなる。盤面の連続タップで早く抜けられる。

## 5. 床のおためし：配置を変えて、組み合わせを比べる

同じ迷路を使うことで、道の違いと素材の違いを混同せずに試せます。検証ページには9つの配置パターンがあります。

- 全面の床比較／全面氷＋ゴム／氷＋砂。
- 曲がり角の重力／曲がり角の反重力／氷＋重力／氷＋反重力。
- 氷＋砂のタイムトライアル／広いカーブ＋重力・反重力。

滑りやすさ、砂の減速、引く・押す強さ、影響範囲を調整し、設定をコピーできます。壁ダメージと時間制限はありません。タイムトライアルでは設定ごとの自己ベストを端末に保存します。

タイトル内の「床の練習」は気軽に体験する入口、別ページの「床のおためし」は配置や数値を比べるための実験場です。本編・練習と検証ページでは調整値が異なります。

## 6. ボールのおためし：5素材の慣性・反発・音を比べる

素材の違いは見た目だけでなく、動き始め、止まり方、壁での反発、重力・反重力への反応、音にも持たせています。以下は現在の試遊値の特徴であり、本編での役割や採用値を確定したものではありません。

| ボール | 試している動き | 試している音 |
|---|---|---|
| ビー玉 | いつもの転がり方。比較の基準 | 硬く細かなガラスの転がり音と衝突音 |
| 金属 | じわっと動き始め、勢いが長く残る。力場への反応は控えめ | 低く連続する重いゴロゴロ。金属らしい響きの衝突音 |
| 木 | なめらかに転がり、少し余韻を残して止まる | 短い乾いた転がり音。壁では乾いた「コン」 |
| スーパーボール | 大きくはずみ、力場にも強く反応する | 転がり音は付けず、壁で弾む音を鳴らす |
| スポンジ | 入力への反応が軽快。止まりやすく、反発は小さい | 転がり音は付けず、壁で小さく「ポフッ」 |

広場と迷路の2種類、普通・氷・砂・重力・反重力・氷＋力場の6床、既存6壁を切り替えられます。広場にも短い仕切りがあり、完全に壁のない面ではありません。球の大きさをそろえ、素材・床・壁の切り替えでは位置と速度を保って比較できます。

加速・減速・反発・力場への反応も数値で調整・共有できます。時間制限・げんき消費・成績の保存はなく、ゴール後も続けて試せます。

音は単に大きさを変えるのではなく、材質ごとに音の有無や響きを見直しています。金属の転がりは打音の連打を避け、木の壁音は短い「コン」へ調整済みです。こけ・とげ壁は選択できますが、検証用の専用音色はまだなく、標準壁と同じ条件です。

## 7. 検証の進め方と、まだ決めていないこと

強い反発や大きな慣性も、配置の工夫によって遊びになる可能性があります。そのため、素材の役割や組み合わせを試す前に決めつけず、技術的に難しい条件も検証候補として残す方針です。

検証ページの初期設定では、合成した速度・反発などを本編向けの上限に丸めず、氷だけ傾きへの反応を弱める補正も外しています。「以前の調整」との比較もできます。入力・計算・音には条件が残り、計算を続けられない場合は条件と理由を残して一時停止します。無条件・無制限の物理実験ではありません。

**未確定の本編への取り入れ方**

- ボールを自由に選ぶか、面ごとに変えるか、ほかの方法にするか。
- 素材の組み合わせに応じた面構成と、げんき・時間・難易度の調整。
- 転がり音の自然さと、連続する跳ね返りの気持ちよさ。実端末での試遊を続ける。

**未実装のアイデア**

- 一部で反発を吸収する綿の壁、げんきを回復する壁。
- 傾きに応じてスライドする、ラケットのような壁。
- 仕切りの少ない面や、反発の連続から偶然ゴールする面。
- コルクを基本の壁にする構成。

スーパーボール＋ゴム壁は検証ページに残しています。現時点では本編へ採用する組み合わせから外す方向ですが、吸収壁などとの組み合わせで再検討する余地があります。アイデアの実装時期や採用は未定です。

## 8. LP編集時の扱い

### おすすめの掲載順

1. 本編の盤面と「すべって、はずんで、迷路を抜ける。」を見せ、遊ぶリンクを置く。
2. 氷で滑る・砂で減速する・力で軌道が曲がる、の3つを画像や短い動画で伝える。
3. 「素材を試す実験も公開中」として、床・ボールのおためしを紹介する。

5種類のボールの画像は「検証中」の表示と一緒に使うと、本編で選べるという誤解を避けられます。動きや音の紹介には、静止画に加えて短い動画が向いています。見せ方の提案であり、LP用の撮影素材は本資料には含めていません。

### 掲載する際に正確に伝えること

- **公開試遊中の開発版**。本編で遊べる要素と、別ページの検証を区別する。
- **迷路はプログラムで自動生成**。ゲーム実行中に生成AIやLLMを使う機能はない。元々の「破綻しない迷路を自動生成する」という検証の狙いと、現在の実装方法を区別する。
- **ゲームとしての手触りを試している**。実物の質量や回転を忠実に再現した物理シミュレーターとは説明しない。
- **傾き操作は端末・ブラウザ・許可状態に依存**。使えない場合はタッチ・クリックで遊べる。全画面や縦向き固定も対応環境で要求する仕組み。
- **記録は端末内に保存**。全国ランキングやアカウント間の同期は実装していない。
- **オフラインは事前の読み込みが条件**。必要なデータをオンラインで保存した後に利用できる。

本資料はLP掲載用の原稿です。現行ページには開発中表示と検索対象外の指定が残っており、この資料作成で公開設定を変更したものではありません。

### 確認済みの範囲と、引き続き評価する範囲

2026-10-04のv0.6.14は公開済み。自動テスト176件、Chromeの3画面幅での床配置・回復・脱出・継続状態、本編の通常／やさしい各1〜16面の画面操作による通し確認を行いました。公開版でも105資材の一致、3幅96画面、102資材の完全オフライン動作を確認。[最新の検証記録](verification/branch-floors.md)。

素材・床・壁などの720条件は2026-10-03のv0.6.13で検証し、697条件が6秒の計算を継続、23条件は計算精度や処理量の理由で停止しました。停止も記録に残しており、「全組み合わせが問題なく遊べる」という意味ではありません。

これらは機能の動作確認です。人間にとっての難易度、素材の面白さ、実端末での傾きや音の自然さは、試遊しながら追加評価する範囲です。
