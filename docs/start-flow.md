# タイトル・準備カウント・ポーズ（v0.2.3 / T-219）

## ユーザーの希望と動作

- タイトルに迷路を出さず、モード選択から始める。上がプラクティス、下がチャレンジ。設定と記録を同じクリーム色のメニュー内へ置く。
- モード選択後は盤面中央にトイ調の「READY / 3・2・1」を表示。球・HP・制限時間は準備中に進行しない。
- 次面・練習リトライ・コンティニュー・ポーズ解除でも3カウントを置く。数値は `UI.startCountdownMs = 3000`。
- プレイ中に押しやすいよう、ポーズボタンを盤面直上へ移動。一時停止中は中央にも「再開」を表示する。
- クリア／失敗トーストを非モーダル化し、表示中も設定・基準の取り直し・壁の凡例・結果への移動を使える。終了済みの面を一時停止する操作だけは無効。
- トースト表示中に設定を開き、閉じると元のクリア／失敗状態へ戻る。記録やコンティニュー残数を変更しない。
- 設定表示・タブ非表示中はカウントを進めない。プレイ画面へ戻ったら手動で再開し、新しく3秒の準備時間を取る。

## 入力と状態

初回のモード選択クリックからiOSのセンサー許可を直接要求する。同じタスクの再選択では再要求しない。拒否・非搭載・無応答時の擬似傾きへのフォールバックは維持する。

準備中の傾き／ポインターは物理へ渡さず、カウント完了時に入力をリセットする。押しっぱなしや準備中に蓄積した入力で突然走り出さない。完了フレームでは物理を進めず、次のフレームから既存の移動開始条件で時計が動く。

画面遷移は既存の `screen`、準備時間は独立した `countdownMs` で管理する。メニューでは盤面とヒントをhiddenにし、描画とリサイズを省く。ゲームとトーストの間の盤面位置は固定し、フォーカスはpreventScroll付きで移すがTabを閉じ込めない。

カウント中の大きなフレーム間隔は `UI.countdownMaxStepMs = 250` で制限し、復帰直後に3秒が飛ぶことを防ぐ。動きを減らす設定では数字のアニメーションを省き、3秒の準備自体は維持する。
