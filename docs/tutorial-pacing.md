# T-241 チュートリアルの説明テンポ（v0.5.1）

- 標準壁を主体とし、特殊壁は各1区間。短い仕切りを追加した固定迷路をBFS検証する。床・アイテムの種類は維持。
- 接触から0.7秒は動きを見せる。説明は迷路下の常設150px枠へ表示。表示による盤面位置・寸法変更や自動スクロールなし。
- 表示開始から1秒だけ物理・床時間を停止。その後は説明を残して操作できる。表示時間は合計4秒。タップで早く閉じることも可能。
- 説明は種類ごとに初回のみ。表示中と終了後4秒は新しい接触をため込まない。未説明の素材は、その後の再接触時に説明する。
- 手動ポーズ、設定、カウントダウン、タブ非表示中は説明時計も停止。とりもちの拘束時間も1秒の停止中は進めない。
- 閉じるとき、既に操作再開済みなら入力・床進捗をリセットしない。BGMは物理再開に合わせる。
- 実機調整値はTUTORIAL.contactDelayMs / pauseMs / lessonMs / lessonGapMs。
