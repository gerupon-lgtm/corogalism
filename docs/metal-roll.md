# T-267 金属の転がりを低くつながる音へ / v0.6.9

ユーザーの指摘：「金属製のボールってバタバタって鳴りますか？」。短い打音を抑え、滑らかな床を重い金属球が転がる想定に合う、低くつながる質感へ見直す方針に合意。

v0.6.8の金属は22–66ms間隔の接触粒に、15msの減衰を付けていた。一定速度でも音の強弱が短い間隔で大きく変わり、打音の連打として目立つ可能性がある。金属はこの粒の方式を廃止する。木／ビー玉の短い接触粒、柔らかい球の転がり無音、全素材の衝突音は維持する。

金属専用の連続成分を作り、低い接触の成分と少量の中低域の質感を重ねる。持続する正弦波や周期的な打音は加えない。音量の揺れはゆっくり・小幅にする。低域の余分な直流成分と高域の擦れを抑え、氷／砂は床に沿って帯域を変える。外部録音を使わないブラウザ合成。

4秒の同じ入力を2回通してフィルタを安定させ、音源の継ぎ目で状態をリセットしない。普通／氷／砂それぞれ、旧版のRMSをほぼ保つ。速度に沿う音量／再生速度、0.12セル/sの開始しきい値、ミュート・非表示・ポーズ停止、停止60ms、衝突の発音条件は維持。物理と本編音声に変更なし。

「おためし4」、共有JSONはrevision4。平均音量の変更ではなく、短い間隔で刻まれる音の構成を見直した。[検証と変更前後のWAV](verification/metal-roll.md)。自動検証は刻みを減らしたことと機能を確認する。音が自然に聞こえるかを人間の試聴なしに保証しない。
