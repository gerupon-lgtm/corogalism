# v0.8.13 更新チェック後のトップ配置を保持

2026-10-25、T-307。最新版をチェックするとトップのサイズが変わる報告への対応。v0.8.12の設定スクロール対策・見出し変更も含む最終公開版。

原因は「最新版です。」をトップ最下部に独立した段落として追加し、部品間の余白を再配分していたこと。393×740のブラウザで外枠が約2.8px高くなり、カードやボタンも移動することを修正前に再現した。

更新結果の表示先を、既存の下部欄の著作権と更新チェックボタンの間へ移す。「最新版です。」は新しい行を増やさず表示できる。更新処理・ライブ読み上げ・更新通知・記録保存は変えない。長い失敗理由は読めるよう折り返す。表示・資材URLとprecacheは0.8.13へ更新する。

## 確認

ローカルChromeで実際に更新チェックを押し、「最新版です。」の表示後にトップの外枠・見出し・チュートリアル・プラクティス・チャレンジ・記録欄・補助ボタン・下部欄の位置と寸法が完全一致することを確認した。5画面条件すべて成功。

同じ手順内でv0.8.12の設定画面も再確認。設定はトップ・ゲーム中からともにスクロール0、26pxの見出しとキャンディ・砂時計・コルク壁を実描画。全画面の補足開閉、角度・音量の保存、音ON/OFF、ゲームへ戻る時の一時停止、134資材のオフライン再読込も成功。エラー0。設定の補足を開いた時は説明を読むためのスクロールを許容する。実機のブラウザバー・センサー・音の感触は未確認。
