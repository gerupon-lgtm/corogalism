# 盤面外の通知（T-280 / v0.6.23）

Pixel 6aを基準に、通知がボールや細かい通路を隠す問題を改善する。ユーザー指定は「端末を傾けて〜」への重ね表示と、現状から無駄に縦幅を増やさないこと。2行の専用欄を追加する案から変更した。

- 葉っぱのまもり、げんき回復、砂時計、ひとやすみ、とりもちの案内、床への接触説明を盤面外へ移す。
- 通知中だけ元の操作案内を見えなくし、通知が終わったら戻す。案内の占める高さは変えない。
- 通知自身は配置上の高さを持たず、既存の操作案内へ重ねる。高さ800px以下では従来から操作案内が省略されるため、盤面と下部の数値の間の隙間に1行で置く。盤面サイズ、下部ボタン、ページの高さを増やさない。
- 通常は12px・1行16px、短い画面は11px・1行14px。大きい新規カードや縦の余白を追加しない。文字は既存のクリーム色・緑に合わせる。
- 同時表示は1種類。とりもちの脱出・ひとやすみ等の操作案内、取得／回復、床の説明の順に優先する。表示待ちの列は作らない。
- とりもちの案内は1行へ整理し、ダブルタップと、対応端末での本体への軽いトントンを伝える。短縮量、自然脱出、入力判定は変更しない。
- カウント中・ポーズ・クリア／ゲームオーバーでは通知を隠す。新しい面では通知をリセットする。表示時間と床説明の接触判定は従来の設定を使う。

表示要素は`#screen-game`内の`#play-notices`へ移し、既存の通知IDを維持する。位置は下部パネルから既存の案内へ重ねる。通常は上へ25px、短い画面は上へ7px。背景と文字だけにし、盤面への入力やボタン操作を遮らない。

## 確認の基準

[GoogleのPixel 6a仕様](https://support.google.com/pixelphone/answer/7158570?hl=ja)の画面は1080×2400。ブラウザ上の表示寸法はAndroidの表示サイズ等で変わるため、今回は412×915・倍率2.625を基準の想定値とし、393×873、360×800も確認する。実機から寸法を取得したという意味ではない。320×568も追加し、通常表示／実際の全画面で旧版と盤面・数値・ボタン・ページ全体の寸法を比較する。

ゲームの物理、迷路生成、げんき・時間・記録、開始時の姿勢確認や待機、音は変更しない。両おためしの共有revision7／9も維持する。表示版をv0.6.23、配信用キャッシュ識別子も更新する。
