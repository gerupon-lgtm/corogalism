# T-290 動く壁のあそび方の操作ヒント / v0.7.1

氷では球の勢いが残る一方、戸は同じ傾きで移動する。方向だけの説明では、切り返す時機やゴールの受け口が分かりづらい。６面の紹介コースで、現在の球と壁の状態に合わせた次の操作を一つずつ表示する。

## 表示

「動く壁のあそび方」と、基本の遊び方から続く同じ６面へ適用する。面の題名と目的は常に残し、綿・ラケット・戸に接触しても一般の素材説明へ置き換えない。目的を短くし、その下へ紫色の操作ヒントを表示する。時間・げんき切れなしの補助説明も残す。

盤面外の既存150pxの説明枠を使う。新たな盤面上の表示、専用パネル、スクロール増加、待機、音は加えない。目的とヒントが同時に読めるよう、コース内の重複する「そのまま操作できます」は省く。基本の素材紹介面の接触説明は従来どおり。

## 判断

案内はDOMから独立した `src/game/puzzleHints.js` で判断する。生成済みの通路・待機場所・戸の開閉位置・通り方と、現在の球の位置と速度、戸・ラケットの位置、現在の傾きを参照する。種に応じた回転・反転後の座標から「右」「左」「上」「下」を決め、写真の向きに固定しない。静止壁に遮られる位置では、1/4マスの通路情報を再利用して壁の端を回る行き先を案内する。この追加判断は紹介コースだけで使う。

次の通路へ近づく、戸を開く、勢いを残して切り返す、囲いの入口へ回り込む、という場面を案内する。綿で狙い直せることは補助行に残す。落ち戻った場合は通路手前の案内へ戻す。球がすでに進んでいる方向や速さも見て、傾きの維持・減速・水平への戻しを使い分ける。

通常の文言変更は250msの安定を確認し、同じ案内を最低900ms保ち、操作の細かい揺れで方向が頻繁に切り替わらないようにする。切り返す時機の案内はこの待機を省いて表示する。開始待機、ポーズ、設定、非表示中には判断の時間を進めない。

ヒントは補助であり、決められた手順を強制しない。物理、壁の反発、摩擦、面の生成、クリア条件、本編の時間・げんき・記録は従来どおり。ラケットの接触回数による解錠などは追加しない。

## 確認

[検証記録](verification/puzzle-hints.md)に単体、ブラウザ操作、画面寸法、オフライン、公開版の照合を残す。自動操作の通過・完走と、実機でヒントを読みながら傾ける難しさを分ける。Pixel 6a実機の読みやすさ・操作のタイミングは公開後も確認する。
