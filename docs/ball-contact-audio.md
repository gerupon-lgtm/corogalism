# T-266 素材ごとに転がる音の有無から見直す / v0.6.8

ユーザーの再評価：音量ではなく、不自然な音が「うるさく」感じられる。柔らかいスーパーボール／スポンジにも転がり音が必要なのか、硬い木／ガラスの音を分けてほしい。T-265の共通の擦れノイズは、この体感を満たさなかった。

今回の盤面では、柔らかい球の転がりを無音として扱う。実物がどの床でも完全に無音という主張ではなく、聞こえるほどの転がり音を常時足さないゲーム上の選択。

| 素材 | 転がりの表現 |
|---|---|
| スーパーボール | 転がり用の音源を作らない。壁では従来の弾む音 |
| スポンジ | 転がり用の音源を作らない。壁では従来の柔らかい音 |
| ビー玉／ガラス | 高域の短い、硬く細かな接触。隙間は無音 |
| 木 | 中低域の短い、乾いた接触。隙間は無音 |
| 金属 | 低域の接触を不規則に重ねる重いゴロゴロ |

`src/audio/ballMaterialAudio.js`の素材別プロファイルから短い接触粒を合成する。木・ガラスには連続するノイズを重ねない。金属は粒の長さと密度を変え、固定音程や一定周期の振動を主成分にしない。各素材の種を分ける。外部録音を使わないブラウザ合成であり、実物の録音そのものを再現したとは主張しない。

普通・氷・砂で接触の密度／減衰を変える。氷は接触を減らし、砂は余韻を短くする。砂にも一律の大きな擦れノイズを足さない。柔らかい球はどの床でも転がり用の音源なし。力場の専用音は追加しない。

素材を替えると旧素材の転がり音を60ms以内に停止。実速度に沿う音量／再生速度、低速しきい値0.12、既存rollingGain0.25、共通音量60%は維持。壁の衝突音20組のPCM・発音条件・ゲインは維持。ボールの物理・本編音声・難易度・練習には変更なし。

ページは「おためし3」、共有JSONはrevision3。柔らかい球の説明に音の有無を短く含め、全素材で転がり音が鳴るという旧文を削除する。ガラスも比較WAVへ追加する。

検証は[記録](verification/ball-contact-audio.md)。柔らかい球の無音は音源開始の実呼出しを観測し、硬い3素材の合成・停止、柔らかい球の壁での発音、音源故障でも遊べること、オフライン動作をChromeで確認する。音色が実端末でどう感じられるかは試遊評価に残す。
