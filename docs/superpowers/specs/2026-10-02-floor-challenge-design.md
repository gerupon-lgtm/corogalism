# 床素材の本編追加・難易度・通常限定体験

2026-10-02 / T-258 / 設計レビュー用。実装・公開は未実施。

## 目的と合意

床のおためしで確認した氷・砂・重力・反重力と組み合わせを、既存チャレンジへ追加する。面の形はシードから自動生成し、固定コースに置き換えない。ユーザーはやさしいで約16面まで進めたが、げんき切れと厳しい時間制限を感じている。両難易度を下げ、新素材を体験する前に難しさや単調さで離脱する状況を避ける。

合意済み:
- 全面氷＋全ゴム壁を採用する。
- その他の床・力場の組み合わせも広く採用する。
- 低ダメージのコルク壁を追加し、面限定のダメージ免除ではなく素材の性質で安全性を作る。
- 力場は初めにカーブの補助として紹介し、後から妨害する配置も出す。
- 通常も易しくし、専用の特別面・ジングル・ゴール演出を遊ぶ理由にする。
- やさしいから通常への案内は控えめにする。
- 公開前にブラウザで動作と実操作を確認し、不具合と難易度を修正する。

以下の登場順と数値は実装の初期案。公開前の検証で調整し、最終値と根拠を記録する。

## 面の進行案

テーマの順は面数と難易度で決定する。迷路・配置はランのシードで変わり、リトライでは再現する。

| 面 | 共通の体験 | 備考 |
|---|---|---|
| 1–2 | 基本操作 | 標準壁、短めの経路候補を優先 |
| 3 | 砂で減速 | 通常床の短い区間に砂、コルク壁 |
| 4 | 全面氷＋全ゴム | 反発と慣性、外周もゴム |
| 5 | 重力でカーブを補助 | 通常床、広いカーブ、コルク壁 |
| 6 | 氷＋砂 | 曲がり角の手前の砂でブレーキ |
| 7 | 反重力でカーブを補助 | 通常床、広いカーブ、コルク壁 |
| 8 | 氷＋補助力場 | 少数のカーブで組み合わせを体験 |
| 9 | やすらぎの面 | こけ主体で緩急を作る |
| 10 | 通常：特別面／やさしい：氷＋砂 | 通常限定の滑走と連続する広いカーブ |
| 11–16 | 既存壁、とりもち、妨害力場を順に追加 | 危険な壁の面と強い床の面を分け、間に安全な面を挟む |

11–16面の初期順は、とりもち→石の面→重力の妨害→やすらぎ→反重力の妨害→氷＋補助。17面以降はこれまでのテーマを安全面と交互に巡回する。トゲは17面以降の独立した腕試し面から少量導入する。通常限定面は10面ごとに再登場する。

既存のSTICKY.firstStage/intervalによる強制割り込みは新しいテーマ進行に統合し、3面目の砂がとりもちで置き換わらないようにする。

## 自動生成と配置

7×7の生成を維持。初登場と特別面は同じ元シードから最大6候補を決定的に生成し、経路長と折れ点で選ぶ。初登場は経路30セル以下を優先し、条件を満たさなければ候補内の最短を選び、生成を終えない再抽選はしない。

砂は正解経路の曲がり角直前に配置。砂単独面では短い区間だけに置き、全面砂による長い低速移動を避ける。氷は全面ゴム面では全面、その他はテーマに応じて部分または砂を除く全面とする。

補助力場は入口側の反重力、出口側の重力を使い分ける。広げられる内角を最大3か所選び、2×2セルの曲がる余裕を作る。変更後に壁・最短経路・経路長・折れ数を再計算し、BFS到達性を検証する。床配置・アイテム配置・HP・時間は変更後の迷路に基づく。

妨害力場は通常床から紹介し、進む方向に逆らう力を少数配置する。開始・ゴール近く、力場が重なる狭い通路、脱出しにくい袋小路を避ける。適地がなければ数を減らす。通常限定の特別面は広いカーブと複数の補助力場の組み合わせを専用構成とし、一般の補助力場面は両難易度で遊べる。

初期値は氷摩擦0.08、速度依存加速の下限0.28・基準速度1.2、砂3.2、力場半径1.6セル。力場は補助3.3、初登場の妨害3.3、後半でも最大6セル/s²。開始前に力場で球が動かないことを確認する。力場は壁越しに働く既存仕様のため、反対側の通路まで含め配置を評価する。

## 壁と既存アイテム

コルクは通常壁と同じ反発係数、ダメージ係数0.25を初期値とする。こけより反発し、ゴムほど跳ねない。淡い茶色の粒と柔らかな接触音で識別する。通常のダメージ閾値・単発上限・無敵時間を通す。

全面氷＋ゴム以外の強い床・力場面は、外周を含めコルクを基本とする。石・トゲを重ねない。石・トゲは通常床の独立テーマで少量登場させる。

キャンディ・葉っぱ・砂時計は引き続き出現可能。力場中心・高速の滑走区間など、取得や停止が難しい位置を避ける。ひとやすみは氷と力場の範囲外に安定して停止できるセルがある場合に配置。とりもちは専用面に限り、氷や力場と重ねない。

## 難易度の初期調整

通常のダメージ係数を現行1.0から0.65、やさしいを0.5から0.4へ下げる。通常の回復抽選を20%から40%へ上げ、やさしいは50%を維持。面数に伴うダメージ倍率の上昇は緩め、上限を1.4とする。初期げんきの折れ数係数を面数で減らす方式はやめ、4.0を維持する。

時間は初期案として1セルあたり0.8秒から0.55秒へ40面で緩やかに変化させる。少なくとも通常25秒・やさしい30秒の下限を設ける。折れ数、砂の経路セル数、妨害力場数による加算を行い、初登場はさらに余裕を持たせる。既存の序盤倍率とやさしいの追加時間は新計算へ整理し、意図せぬ重複加算を避ける。

ここでの数値は成功率の保証ではない。初登場面で遅い操作や数回の立て直しが成立することを実装後に測定し、時間・配置・げんきのどれが失敗原因か分けて調整する。通常の専用面を難度上昇のご褒美扱いにはせず、10面目までの到達しやすさを重視する。

## 演出と導線

新テーマ初登場時に、既存READYとカウントダウンの時間内で素材の絵・面名・一言のヒントを表示する。追加の閉じる操作や待ち時間を作らず、リトライで長い紹介を繰り返さない。通常限定面は専用の短いジングルと、ゴール時の控えめな色・粒の演出を持たせる。

ジングルは既存スタート音との重なりを避けて置き換える。再生時間は0.8秒以内を目安にし、BGM開始・音OFF・音量・非表示時停止の規則を維持する。読み込み失敗や音声拒否でも開始する。動きを減らす設定では静止した強調表示にする。

やさしいで8面以上クリアした結果画面に、通常限定面の短い予告を添える。広いカーブを滑る光の軌跡と紫・橙の力場を、既存のトイ調に合う小さな横長の絵で見せる。約0.8秒で光が走って静止画になる演出を目安とし、結果や再挑戦ボタンは初めから操作可能にする。コピーは「もうひとつの滑走」、小さな補足として「通常モード・特別面」とする。「挑戦しよう」などの勧誘文、大きな通常ボタン、強制ポップアップ、閉じる操作は設けない。

4面での早い予告は入れない。初回は8面以上クリアしたランの結果で表示し、以後は同条件の結果3回につき最大1回とする。表示頻度だけを端末内に保存し、保存不可ならページ内で最大1回に抑える。結果の成績や失敗原因を主役にし、予告で既存の結果を隠さない。音を新たに重ねず、既存の結果音を尊重する。動きを減らす設定では最初から静止した絵を表示する。

難易度の切替は結果画面の既存「モード選択」経由で行い、予告を押すことや通常への移行を要求しない。ユーザーの要望は「押し売りにならず、格好よく興味を引く演出」であり、明示的な誘導の量では評価しない。

記録の旧データは削除しない。進行と難易度が変わるため、既存ベストとの単純な比較には限界がある。記録形式に今回のルール版を持たせ、旧記録は旧ルールと分かる形で保持する。

## 実装の接続方針

面テーマの選択を進行の唯一の基準にし、createStageで迷路加工→壁・床・力場→アイテムの順に生成する。通常限定フラグや紹介文はテーマの情報としてUIへ渡す。sampleZone・resolveParamsと既存衝突物理を利用し、実験ページ専用の固定seed250を本編から参照しない。

おためしで確認した床描画・力場描画は本編からも利用できる共通描画にする。氷・砂・重力・反重力・コルクをあそびのガイドへ追加する。実験ページの調整値は本編の設定と分離する。

## ガイドの追加要望（2026-10-02）

ユーザーはガイド更新も依頼し、スクロール量より楽しさの伝わりやすさを優先することを指定した。

冒頭に「すべる・曲がる・軌道が変わる」の3つの遊びを、氷の滑走線、砂でのブレーキ、紫と橙の力場の絵で紹介する。力の向きは絵の矢印と短い説明を併用し、色だけで識別させない。絵は本編と描画を共有し、音なし・静止画でも伝わるものにする。通常限定面の紹介はここでは小さな補足に留め、初心者が全素材を学べるガイドを主役にする。

壁は6種類を2列の短いカードにまとめる。コルクの「ほどよくはねる・痛み少なめ」と、ゴムの強い反発、こけの弱い反発を区別する。氷・砂、重力・反重力はそれぞれ隣り合う比較カードにし、慣性・ブレーキ・引く／押すを読み取れる絵を優先する。ひとやすみ・とりもち、3アイテムの既存説明も残す。

アイテムは横長の短いカード、床は絵が見える比較カードとし、見出しの空白と文章の重複を削って増加を抑える。スクロール量の固定上限は設けず、320px幅で文字や絵が小さすぎないことを確認する。ガイドを閉じたときのフォーカス復帰・背景スクロール復帰・PAUSE維持・全画面カメラ余白を保つ。

## 公開前の検証

1. 到達性、決定的再現、加工後の経路と時間、配置の禁止条件、コルクの反発・ダメージ、両難易度のテーマ順を検証する。
2. 複数シードの各テーマを、遅い反応・曲がり損ね・遅めのブレーキを含む操作モデルでも評価する。完全な自動操縦の合格だけで易しいとは判定しない。
3. ブラウザで画面の入力を使って最初から進行し、停止・再開・失敗・コンティニュー・ゴールを確認する。クリア確認にteleportやHPの書き換えを使わない。テーマごとの開発用開始は個別検証だけに用い、通しプレイとは区別する。
4. 320×568、390×844、576×1024で、紹介とガイド・通常への導線・全画面余白・盤面収まりを確認する。音ON/OFF、動きを減らす、センサー拒否・無信号、PWA更新とオフラインを検証する。
5. 通しプレイとテーマ別検証のシード・操作方式・所要時間・失敗原因を記録し、確認で見つけた不具合を修正してから公開する。

ブラウザの画面操作とセンサー模擬では、実端末の持ち方・傾きの触感までは確認できない。自動測定、ブラウザ操作、ユーザーの実機評価を区別して報告し、人間全体の成功率を検証結果から断言しない。

## 完了条件

新しい床・コルク・通常限定体験が既存チャレンジで進行し、両難易度に従来より時間と被弾の余裕があること。紹介は進行を止めず、通常への案内は控えめであること。公開前の動作・バランス確認結果と修正を文書に残し、公開版でも実行資材と主要導線を再確認すること。
