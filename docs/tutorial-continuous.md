# T-242 止まらないチュートリアル（v0.5.2）

- 説明に起因する物理・操作・BGM・床時間の停止を撤廃。
- 初めて触れた素材だけ、接触後0.7秒で説明へ反映。同時接触は重複せず順に反映（更新間も0.7秒以上）。
- 説明は次の更新まで残す。4秒の自動終了・閉じるボタン・残り表示を撤廃。150px常設枠は維持し迷路を動かさない。
- 更新時だけ650ms、説明枠の内側を淡いクリーム色で1回光らせる。画面全体の点滅や音は追加しない。動きを減らす端末設定ではアニメーションなし。
- 手動ポーズ・設定・非表示・カウントダウン中の更新待ち時間は進めない。新しいチュートリアル開始時に説明履歴をリセット。
- 固定面・記録非保存・げんき下限・本編は従来どおり。
