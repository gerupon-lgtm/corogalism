# T-265 ボールの音と反発を再考

2026-10-03。v0.6.6の音量調整だけでは意図を満たさなかった。ユーザーから「音量ではなく、不自然で違和感があり、うるさく感じる」「スーパーボールは最初のリフレクションは良いが2回以降が不自然」「木、スポンジは違和感が高い」。追加確認は「勢いの減り方や、跳ねる間隔が不自然」。

## 原因と変更

- 転がり音は一定の正弦波と固定周期の脈動を混ぜていた。速度を変えても持続する音程があり、モーターのような音になりやすい。固定音程・固定周期を取り除き、4秒の不規則な擦れ、小さな接触による短い共鳴へ変更。金属は低域の厚さ、木は乾いた接触、ゴムは柔らかい擦れ、スポンジは弱い擦れ。氷は滑らかで静か、砂は粒感を足す。
- 転がり音は0.12セル/s以下で停止。音量は速度とともに0から連続的に増やし、減速中に一定音量を残さない。T-264の控えめな出力と共通音量は維持する。衝突音20組合せのPCM・発音処理は維持。
- 反発は衝突速度を渡してresolveParamsで解決する。強い最初のゴム球の反発上限0.94を保ち、弱い接触は滑らかに反発0へ近づける。回数を数えて一律に弱める処理は入れない。壁に押し続けた時の微小振動が収まる。衝突は従来の円×矩形、反発は法線方向だけ。
- ゴム球の移動中の減衰を0.3→0.2へ緩め、移動中に大きく勢いを失い、次の壁まで不自然に長く待つ感じを減らす。木の減衰は3.375→2.25、スポンジ7→4。スポンジの加速度は26.35→19.55、力場倍率2.5→1.5。極端な初動と急停止を和らげ、短い余韻を残す。

## 範囲

専用ページを「おためし2」へ更新し、共有JSONをrevision2とする。本編・床の練習のキャラ、基準物理、HP・記録は維持。新しい`bounce`属性を持たないキャラは従来の反発率。新コアのない旧PWAは更新へ案内する。

パラメータは[ボール素材仕様](ball-material-lab.md)に記載。物理係数と安全範囲はgameConfigへ集約。音と操作の自然さを自動テストの合格で断定せず、公開した試遊の体感で追加評価する。
