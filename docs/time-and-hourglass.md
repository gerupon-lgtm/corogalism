# T-232 制限時間・砂時計・ゴム壁（v0.4.3）

ユーザー承認: 時間は実秒で減算。やさしいの9面以降の制限時間を増やす。砂時計A案を現在の世界観で追加し、ゴム壁の反発を強める。

- やさしい1〜8面と通常全体は時間設定を維持。やさしい9面+3秒、10面+6秒、11面+9秒、12面以降+12秒。経路長から求める従来の制限時間へ加算。設定はEASY_TIME。
- 木枠・金色の砂・淡いガラスのトイ砂時計。9面以降最大1個、やさしい50%／通常20%。経路55〜85%の空きセルに抽選配置。キャンディ・葉っぱ・休憩・とりもちと同じセルを避け、既存配置を優先する。候補がなければ出現なし。設定はHOURGLASS。
- 取得で残り時間+5秒、取得済みは消える。クリアタイムを差し引かず、ノーミス判定を変えない。時間切れ・げんき切れが優先。取得表示と柔らかな上昇3音SE。音OFFを尊重する。
- コンティニューは制限時間をリセットするため砂時計も同じ位置に復元。加算時間の次面・次試行への持ち越しはない。既存の葉っぱ・休憩使用履歴は維持。
- ゴムの反発倍率1.5→2.0、実効反発0.525→0.7（通常0.35）。resolveParamsと既存クランプを維持。damageK=0.4のまま。
- 時間と反発の体感は公開後の実機試遊で追加調整する。
