# T-240 はじめてのあそび方（v0.5.0）

**v0.5.1:** 表示場所・停止時間・素材配分は [tutorial-pacing.md](tutorial-pacing.md) が最新。以下はv0.5.0の導入時点の記録。

承認済みの3画面コンセプト（縦持ちに修正）に基づく固定面チュートリアル。

- トップのプラクティスより上に入口。開始案内は迷路を隠し、縦持ち・画面を上・奥側を少し上げるイラストを表示。
- 開始ボタンの操作からセンサー許可を取得。傾きモードではこの姿勢を改めて安定計測して基準にする。未対応・拒否・無信号は既存のタッチ操作にフォールバック。
- 7×7の広い蛇行通路。全セルBFS検証。標準・ゴム・石・とげ・こけ、ひとやすみ・とりもち、キャンディ・葉っぱ・砂時計を固定配置。迷路は概念図の装飾より通りやすさを優先。
- 時間制限なし。げんきは100、最低1を保持し終了しない。物理とダメージ式（速度・素材による差、閾値・上限）は本編を共有。全アイテムと床を操作できる。時間加算はチャレンジ用であると説明。
- 壁への衝突・床やアイテムへの接触で説明。ガイド本文と描画を共有。壁には「ぶつかる速さと壁の素材で、げんきの減り方が変わります。」を追加。
- 説明は種類ごとに初回だけ。同時接触は1件ずつ表示。タップ（ダイアログ／背景）・閉じるボタン・Escapeまたは4秒で終了。TUTORIAL.lessonMsで調整。
- 説明中は物理・とりもち・ひとやすみの時間を停止し、BGMも停止。閉じる操作を脱出タップとして数えず入力をリセット。自動終了フレームの停止経過時間を物理に足さない。タブ非表示で説明時計を止め、復帰後は明示再開。
- ゴールで「できた！」。同じ固定面を再度遊ぶかモード選択へ。チュートリアルは自己ベストを保存しない。既存の記録は変更しない。
