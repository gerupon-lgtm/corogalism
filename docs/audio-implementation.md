# T-221 / v0.2.7 サウンド実装

2026-09-12。ユーザー承認済みの試聴版v2（4分音符の控えめなパーカッション）を採用。

- 盤面上のポーズの左に「音 ON / OFF」。設定画面にも同じ切替とBGM・SEの独立音量。
- 初回OFF、既定BGM60%・SE80%。設定はlocalStorageへ保存。保存不可でもその場の操作は有効。
- 音ONの操作後に同梱14音源を読み込む。Web Audioをクリック内で有効化し、保存済みONでもページを開いただけでは再生しない。
- BGMは100 BPM・38.4秒ループ。選択、3/2/1/開始、速度連動の転がり、素材別衝突、ゴール、クリア、失敗、コンティニュー、ポーズにSEを接続。
- BGMはカウントダウン終了後の操作可能なプレイ中だけ再生。カウントダウン、ポーズ、設定、モード選択、クリア、ゲームオーバー、ラン結果、非表示タブでは停止。停止時の60msフェードでクリックノイズを抑える。SEは従来どおり発音。
- v0.2.7でユーザー指示を反映し、タイトル・準備中のBGMと結果画面の減音再生を廃止。
- 微小衝突の除外、90msの衝突音間隔、SE同時8音まで、フェード、共通リミッターを用意。ゲームのHP・物理判定は音に依存しない。
- 読込失敗は音源ごとに隔離（15秒タイムアウト）。OFF→ONで再試行。遅れて読み込まれたSEを後追い再生しない。API非対応でも無音で遊べる。
- 「開発中の技術検証です（フェーズ2）」とnoindexは維持。
- ヘッダの2段コピーの最終行「A BIG FEELING」をロゴ末尾mの下端（ベースライン）へ揃える。バージョンはロゴと同じ行。

実装入口: `src/audio/soundManager.js`、`audioSettings.js`、`src/main.js`。
音の設定値は `src/config/gameConfig.js` のAUDIOへ集約。音源の由来は `assets/audio/README.md`。

検証: `test/audio-settings.test.js`、`test/stagePlay.test.js`、`tools/browser-audio.mjs`。
ブラウザ検証は初回無音、14音源のデコード、各ゲームイベント、停止／再開、独立音量と保存、配置・注記、API非対応・通信失敗・読込途中OFFを確認。
ヘッダは `tools/browser-ui-polish.mjs` で320/375/390/464/1280pxを確認。
iPhone / Android実機の音量感・割り込み後の試聴は公開後の確認事項。
