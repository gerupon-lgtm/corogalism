# T-221 / v0.2.9 サウンド実装

**v0.2.10追記:** カウント前に通常0.6秒・コンティニュー1.5秒のREADYを追加。コンティニューSEとカウント音の重なりを避ける。開始SE後のBGM待機は維持。`results-and-timing.md` 参照。

2026-09-12。ユーザー承認済みの試聴版v2（4分音符の控えめなパーカッション）を採用。

- 盤面上のポーズの左に「音 ON / OFF」。設定画面にも同じ切替とBGM・SEの独立音量。
- 初回OFF、既定BGM60%・SE80%。設定はlocalStorageへ保存。保存不可でもその場の操作は有効。
- 音ONの操作後に同梱14音源を読み込む。Web Audioをクリック内で有効化し、保存済みONでもページを開いただけでは再生しない。
- BGMは100 BPM・38.4秒ループ。v0.2.9より毎回曲の先頭から開始し、停止位置を引き継がない（次面・再挑戦・ポーズ再開・音ONへの復帰も同じ）。選択、3/2/1/開始、速度連動の転がり、素材別衝突、ゴール、クリア、失敗、コンティニュー、ポーズにSEを接続。
- BGMはカウントダウン終了後、スタートSE（0.8秒）＋間（0.2秒）を待って、操作可能なプレイ中だけ再生。カウントダウン、ポーズ、設定、モード選択、クリア、ゲームオーバー、ラン結果、非表示タブでは停止。停止時の60msフェードでクリックノイズを抑える。SEは従来どおり発音。
- v0.2.7でユーザー指示を反映し、タイトル・準備中のBGMと結果画面の減音再生を廃止。
- 微小衝突の除外、90msの衝突音間隔、SE同時8音まで、フェード、共通リミッターを用意。ゲームのHP・物理判定は音に依存しない。
- 読込失敗は音源ごとに隔離（15秒タイムアウト）。OFF→ONで再試行。遅れて読み込まれたSEを後追い再生しない。API非対応でも無音で遊べる。
- 「開発中の技術検証です（フェーズ2）」とnoindexは維持。
- ヘッダの2段コピーの最終行「A BIG FEELING」をロゴ末尾mの下端（ベースライン）へ揃える。バージョンはロゴと同じ行。

v0.2.8のタイミングは `design/2026-09-12-start-timing/countdown-start-gap-200ms-bgm.wav` でユーザー承認済み。操作開始は従来どおりカウントダウン終了時。音声時計と実時間の両方で待ち、ポーズ・終了・画面移動後にBGMが遅れて始まらないよう、毎フレーム現在の状態を確認する。初回・次面・リトライ・コンティニュー・ポーズ再開に共通。
