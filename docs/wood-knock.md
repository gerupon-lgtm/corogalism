# T-268 木の壁音を乾いた「コン」へ / v0.6.10

依頼：木のボールが壁に当たる音を、乾いた「コン」にする。木の衝突音だけ変更し、転がり音・他素材の衝突音・物理は維持する。

旧版の木は185Hzの低い成分に長めの減衰を付け、「ボン」寄りの響きが残っていた。短い420Hzの胴鳴り、すぐ消える980Hzの成分、ごく短い接触音へ変更。立ち上がりを2ms→0.6msにし、音の後半を早く収束させる。柔らかいゴム／コルク壁ではさらに余韻を短くする。衝突速度に沿う音量、壁の音量差、発音間隔80ms、同時8音などの発音制御は維持。

「おためし5」、共有JSONはrevision5。本編の球はビー玉のまま。音量設定・床と力場の動き・難易度・記録は変更しない。[検証と比較音声](verification/wood-knock.md)。自動検証では短い余韻と発音動作を確認する。「コン」の聴感は実端末で追加評価する。
