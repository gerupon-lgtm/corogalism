# T-229 葉っぱ・床・PWA（v0.4.0）

ユーザー承認の画像 exec-7b6b06c5-13d5-44bf-8908-d7849efd5d24.png を基準に、既存の盤面・厚い素材壁・トイ調カード・操作配置を保つ。HPの表示名は「げんき」、TIMEは「のこりじかん」。内部識別子は互換性のため維持。

## 確定仕様

- 葉っぱ: 正解経路20〜50%の前半〜中盤。やさしい50%／通常20%、キャンディとは独立した抽選。1個で取得面の最大げんき20%分のまもりを加算、50%を加算時上限とする。上限を超える持ち越しは切り捨てない。満杯なら未取得のまま置く。
- まもりはダメージ閾値・単発上限適用後、げんきより先に消費。全額吸収ならノーミス、げんきが減れば対象外。残量は面間・コンティニューで維持、新しいランで0。取得済み葉っぱはコンティニューで復活させない。
- ひとやすみ: 全テーマ。基本・苔・ゴムはやさしい30%／通常20%、実際に石・トゲがある面は60%／40%。正解経路45〜80%、強い壁の直後を優先。他のアイテム・床とは別マス。2秒ほぼ静止で最大げんき20%回復、のこりじかん2秒追加。記録のクリアタイムは差し引かない。移動で進捗リセット、満タンなら未使用、1面1回、コンティニューでも使用済みを維持。
- 休憩中もタイマーは動く。成立前または同時に0ならタイムアップ優先。タイマーを止める特例なし。ポーズ・設定等への移動時は静止判定をリセットする。
- とりもち: 3面目から8面ごと（3/11/19…）に基本壁の専用テーマ。初登場は正解経路上1個、以後は経路外に空きがあれば2個目。正解経路上最大1個。開始・ゴール周囲と他要素を避ける。2秒自然脱出、画面ダブルタップまたは本体への軽いタップ1回で0.5秒短縮、最短0.5秒拘束。一度その床から完全に離れるまで再拘束しない。
- 脱出ヒントは拘束中だけボール近くに表示、クリックを遮らない。足元リングで進捗、本体センサーが届く場合だけ本体タップの補足。センサー未対応・拒否でもダブルタップと自然脱出で遊べる。
- プラクティスは従来どおり、げんき・時間制限・アイテム・特殊床なし。キャンディの既存のコンティニュー再生成は維持する。

## 表現

げんきカード上段にハート＋げんき、右上に葉っぱ＋残量、下段に数値。のこりじかんカードも2段だが旧カードの高さを維持する。葉っぱは薄い緑の光沢と葉脈、まもりは球の外周だけの淡い緑光。休憩床はミントのハート刻印タイル、とりもちは琥珀色の半透明な粘着床と短い糸。静的な素材と進捗以外に激しい点滅を追加しない。参照画像の任意の表示数値・面番号は仕様ではない。

## PWA

ホーム画面追加、standalone起動。全実行資材（音源・フォント・壁画像含む）の保存完了後にオフライン可能。保存状態は設定に表示、失敗してもオンライン通常プレイを妨げない。
更新はタイトルだけに案内し、更新ボタンを押してから適用。プレイ中の自動リロードなし。別タブがある場合は閉じてから更新する案内。キャッシュは資材の内容ハッシュ単位、インストール完了前に旧版を削除しない。保存記録・音設定は既存localStorageを維持する。

配信前: `node tools/update-precache.mjs` でprecache.jsを更新。ビルドシステムは追加しない。アプリアイコンは既存の葉ロゴから生成（`tools/render-pwa-icons.mjs`）。
参考: [MDN PWA](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable)、[Service Worker](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)、[Motion permission](https://developer.mozilla.org/en-US/docs/Web/API/DeviceMotionEvent/requestPermission_static)。

## 調整・検証

LEAF/REST/STICKYをgameConfig.jsに集約。静止速度0.12セル/秒、移動許容0.08セル。モーションは連続サンプル差6m/s²、画面タップとの二重計上を抑止。拘束中だけ短縮として解釈。身体タップ感度は端末・ケースに依存し、実機で調整する。

107テスト成功。browser-features（4幅）、browser-escape-input、browser-pwa、browser-audio、browser-first-sound成功。仕様・規約の2軸レビューで端の配置除外と設定値の共通化を修正し、再レビュー追加指摘なし。

コンティニューの実ブラウザ検証（browser-feature-continue.mjs）成功。残量・取得済み・休憩使用済みの維持と、新しいランでのリセットを確認。
