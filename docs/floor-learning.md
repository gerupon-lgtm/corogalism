# T-261 床の体験と練習（v0.6.3）

**通知の現行差分（T-280 / v0.6.23）:** 床の接触説明は盤面下の既存の操作案内へ重ねる。以下の球の位置に応じた上下移動は旧仕様。脱出等の操作案内、取得／回復、床の説明の順に1種類を表示。接触からの待機・表示時間・素材切替・練習のルールは維持。[現行仕様](play-notices.md)。

v0.6.4では「床の練習」は維持し、やさしいの一律90秒を最低40秒・初登場床45秒＋面の負担に応じた時間へ変更。「はじめてのあそび方」に全素材を追加した。[現行の時間とチュートリアル](tutorial-floors-and-time.md)。以下はv0.6.3時点の仕様。

承認済み方針：やさしいの初登場面を反復体験にし、時間を気にせず素材を比較できる床の練習を追加する。

- やさしいの初登場床面は最低90秒。砂を2–3区間、単独の重力／反重力を2–3箇所に配置し、普通の床と往復して比べられるようにする。力場の中心間は直径以上に離す。氷との混合面も力場は互いに重ならない。通常モードの構成と物理係数は維持。
- 本編の迷路はシード生成を維持。床の練習だけ同じ7×7の広い面を使い、普通・砂・氷・重力・反重力を切り替える。時間／HPの制限なし。物理係数は本編採用値、壁はコルク。ゴールは任意の目標として再試行可能。練習では記録を保存しない。
- 素材の接触が少し続いたら、砂で減速／氷の慣性／中心へ引く／中心から押すを短い説明で表示。ポーズ・非表示タブ・カウント中は進めない。取得物の通知を優先する。
- 切替時はその場で同じ位置と速度を保って比較できる。初期位置へ戻す操作も用意する。再試行は同じ素材・同じ面で行う。制限なしでも既存の全画面・センサー許可／拒否／無信号経路を維持。

検証：複数シードの初登場面、数・間隔・到達性・90秒、本編と同じ物理／記録非保存、ブラウザの実pointerと素材切替、接触説明、停止／再開、画面幅、オフライン、描画性能。公開後の資材一致と主要操作も確認する。人間の傾き体感は実機評価と区別する。

## 実装

タイトルの「床の練習」から直接開始。普通の床の上に3つの素材区間／力場を置き、短い仕切りを目印に往復する。5つの切替ボタンと「最初へ戻す」を盤面上に置く。接触説明は300ms後に3.5秒表示し、再接触で繰り返す。球が上段にある時は説明を下へ移動する。

やさしいの初登場3・4・5・6・7・8・13・15面は90秒以上。力場は最終BFS経路から離れた2点、余裕があれば3点目へ置き、直線上でも中心の引く／押すを比較する。混合面8では重力と反重力を交互に置く。通常モードのカーブを補助／妨害する配置は従来どおり。記録のキーと既存記録は維持する。
