# T-288 本編の傾きパズル / v0.6.31

同じ傾きで球と壁を動かし、球の慣性と壁の停止・切り返しの違いで道を作る。本編のやさしい・通常へ共通で追加する。新しい遊びを後半の一律難化には使わない。

## 面の流れ

既存の床紹介1〜16面を維持し、17面で打ち返し、19面で順に道を開く、21面で切り返し、23面で最初の組み合わせを紹介する。間に既存の迷路を挟み、通常の10面ごとの光の滑走路も維持する。

24面以降は普通の迷路・単独・組み合わせ・息抜きを混ぜ続ける。パズルの初期抽選率は35％で、直近4面の種類を考慮して連続の確率を下げる。固定巡回や後半ほど複雑にする方式ではない。単独3種に加え、道を開く＋打ち返す、順に開く＋滑り込む、打ち返す＋滑り込むを持つ。

組み合わせにも余裕のある面を用意し、通路・ラケットの長さ・狙う距離・綿の待機場所などで緩急を付ける。候補サイズは既存の7/8/9/11/13を使い、候補一覧を計算上限とはしない。

## 生成と到達

検証用の固定7×7全体はコピーしない。種から仕切り・開口・戸袋・綿・内側カップの位置と寸法を選び、向き・反転も変える。ラケット利用回数や順序の達成フラグでゴールを解錠しない。数字は通路の関係を伝える目印。

道を開く＋打ち返す面のラケットは、上側の部屋から次の開口へ球を送る位置に置く。カップを囲む壁が返球を遮る位置は修正した。

静止壁の全マスBFSと最短経路・曲がり回数を計算する。さらに球径の開口・収納した戸・待機場所・全戸を開いた状態の再試行経路を確認する。これらは空間の確認であり、同じ傾きで球と壁を操作して解ける証明とは区別する。動的操作・反発・やり直しは別の物理／ブラウザ検証で確認し、失敗も保存する。

## 感触・時間・げんき

ビー玉・氷・ゴムは既存本編の値。可動壁の初期値は速さ4、反発1.08、中心と端の打ち分け55度。通路の戸は通常の相対反射を使い、ラケットだけ打ち分ける。水平に戻すと壁は入力の短い余韻の後で停止し、球は滑り続ける。

本編・紹介コース・検証ページは `physics/movingWalls.js` を共有する。既存の普通面は従来の積分処理を継続する。綿は壁へ向かう速度を吸収し、壁沿いの滑りは残る。綿・ラケット・戸は無傷。ラケットには既存のゴム音、綿には既存検証の短い吸収音を使う。

初期げんきは両モードとも従来の `40 + 4 × 曲がり回数`。制限時間は従来の経路計算に、壁の移動距離・開閉・返球・切り返し・初紹介の余裕を追加する。やさしいには多めに追加する。値は `PUZZLE_MAIN.time` に集約し、実機の試遊で引き続き調整する。

コンティニューは同じ種・面・仕掛けを初期位置へ戻し、従来どおり時間・げんきを回復する。取得済み葉っぱ／使用済み休憩の扱いは保持する。記録は `puzzle-v1` へ分け、旧 `maze-v1`／`floor-v1` の記録は消さず参考表示する。

## 遊び方と紹介コース

ガイドに綿、ラケット、通路の戸の図解を追加。中心／端の打ち分けと普通の反射を区別し、やさしい・通常共通であることを明記する。

既存「はじめてのあそび方」のクリア後に、単独3面→組み合わせ3面の短い紹介コースへ続ける。タイトルの「壁を動かすあそび方」からも直接入れる。時間制限・げんき切れ・記録保存はなく、説明は盤面外へ表示しプレイを止めない。既知の氷などの説明で新しい操作説明を隠さない。既存のプラクティス・床の練習は保持する。

本編の17／19／21／23面の紹介では、既存のREADY／カウント内で図解と短文を見せ、待機を追加しない。24面以降の別の組み合わせは、既に学んだ操作を使う面として通常のREADYで開始する。プレイ中のヒントも既存の盤面外の案内位置を使う。

確認結果と公開状態は [検証記録](verification/main-puzzles.md)。PCの自動操作・スマホ幅の確認は、Pixel 6a実機の傾き・面白さ・長時間の負荷とは分けて扱う。
