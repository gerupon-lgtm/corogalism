# 床のおためし

**現行T-250 / おためし4:** 7×7固定迷路（seed250）、外周を含め全壁ゴム。通常・氷・砂は全面適用。重力・反重力は16地点（各軸0.5/2.5/4.5/6.5）に同じ力場を配置し、重なりは合成後に設定した力を上限とする。半径を小さくすると力の届かない隙間ができる。「迷路の途中へ」は正解経路の中間セルへ移動。ゴールは右下。切替時の迷路形状・スタートは共通。以下の旧コース・部分床の記述は履歴。

2026-09-22。ユーザー承認: 既存チュートリアルとは別の公開ページで試遊し、正式採用を判断する。

入口は `/floor-lab.html`。本編の床抽選やキャラクターには追加しない。通常・氷・砂・重力・反重力を同じ7×7固定コースで切り替える。左の直線、下の曲がり角、右の広場を配置し、全セルのBFS到達性を検証する。スタートと広場への移動、一時停止、傾き基準の再調整が可能。時間制限、HP消費、記録保存はない。

氷・砂は着色したセルでのみ摩擦係数を変更する。球の中心で判定。氷0.08倍、砂3.2倍が試遊初期値。重力・反重力は広場の中心(4.5,4.5)から半径1.6セル、最大加速度6セル/s²。力の大きさは `4 * strength * u * (1-u)`（u=中心距離/半径）。中心・外縁は0、半径の半分で最大となり、中心でも力が連続。反重力は符号を逆にする。輪の動きも内向き／外向きで区別し、動きを減らす設定では静止する。

摩擦と外力は既存のゾーンとresolveParamsを経由。速度上限、サブステップ、円と矩形の衝突を維持する。床を切り替えると球はスタートに戻り、強さの調整中はその場に留まる。設定はページ内で保持し、再読み込み時に初期値へ戻る。設定コピーに選択床・操作方式・全調整値・試遊版番号を含め、コピー不可時は選択できるテキストを表示する。

センサーは明示ボタンから許可を求め、安定姿勢を基準にする。拒否・非対応・6秒以内に基準取得できない場合は画面操作へ戻す。画面非表示・フォーカス離脱で停止。縦持ちの案内、noindex、開発中表示を維持。

旧PWAが古い共通モジュールを返す場合は、初期化前に判定してトップ画面からの明示更新を案内する。自動更新・自動リロードは行わない。

## T-249 おためし3：氷の慣性と外周線の撤去

ユーザー訂正により氷は調整範囲で最も滑る0.08（実効摩擦0.2/s）へ変更。氷上の加速係数は `0.28 + 0.72 / (1 + (speed / 1.2)^2)`。停止時は1、速度が上がるほど0.28へ近づき、逆方向・横方向への速度変更が緩やかになる。resolveParamsの上限下限と既存の物理積分を維持。氷を離れると通常の加速へ戻る。係数はICE_LABで管理し、本編に氷を配置しない。砂3.2・力6・半径1.6は維持。

重力・反重力の外周点線を削除。膜と方向の流れ、中央円盤は維持。設定コピーと画面表記はおためし3。

新規検証: 初速3での逆入力は通常床の2倍以上の停止時間・距離。初速1.5より停止時間・距離が長い。停止後反転、発進時の加速係数1、直角入力の横滑り、氷の範囲外で通常の加速へ復帰を確認。
