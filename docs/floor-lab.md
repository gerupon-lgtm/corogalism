# T-247 床のおためし

2026-09-22。ユーザー承認: 既存チュートリアルとは別の公開ページで試遊し、正式採用を判断する。

入口は `/floor-lab.html`。本編の床抽選やキャラクターには追加しない。通常・氷・砂・重力・反重力を同じ7×7固定コースで切り替える。左の直線、下の曲がり角、右の広場を配置し、全セルのBFS到達性を検証する。スタートと広場への移動、一時停止、傾き基準の再調整が可能。時間制限、HP消費、記録保存はない。

氷・砂は着色したセルでのみ摩擦係数を変更する。球の中心で判定。氷0.2倍、砂2.4倍が試遊初期値。重力・反重力は広場の中心(4.5,4.5)から半径1.6セル、最大加速度5セル/s²。力の大きさは `4 * strength * u * (1-u)`（u=中心距離/半径）。中心・外縁は0、半径の半分で最大となり、中心でも力が連続。反重力は符号を逆にする。輪の動きも内向き／外向きで区別し、動きを減らす設定では静止する。

摩擦と外力は既存のゾーンとresolveParamsを経由。速度上限、サブステップ、円と矩形の衝突を維持する。床を切り替えると球はスタートに戻り、強さの調整中はその場に留まる。設定はページ内で保持し、再読み込み時に初期値へ戻る。設定コピーに選択床・操作方式・全調整値・試遊版番号を含め、コピー不可時は選択できるテキストを表示する。

センサーは明示ボタンから許可を求め、安定姿勢を基準にする。拒否・非対応・6秒以内に基準取得できない場合は画面操作へ戻す。画面非表示・フォーカス離脱で停止。縦持ちの案内、noindex、開発中表示を維持。
