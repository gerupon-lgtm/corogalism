# v0.8.16 葉っぱのまもりを見やすくする

2026-10-25、T-310。げんきカード内で小さかったまもりの残量を、輪郭のある札として表示する。葉っぱは12pxから17px、数字は9〜10pxから14〜15px・太字900へ変更し、通常幅では「まもり」の見出しを添える。狭い幅では見出しだけを省き、葉っぱと数字を維持する。

残量がある場合は薄緑の札と濃い緑の文字、0はベージュの札と濃い茶色の文字で区別する。読み上げ用の名前にも「残り」を付ける。数値は従来どおり実残量の切り上げ表示で、葉っぱの枚数への変更ではない。吸収量・取得条件・持ち越し・上限は変更しない。

げんき・時間カードと迷路の位置・寸法を維持する。チャレンジのげんきカードの内側余白と二段組を調整し、時間とげんきのバーを同じ高さに揃える。チュートリアルの横並びは維持し、大きい残量表示とダメージ表示が重ならないよう位置を調整する。練習では従来どおりげんきカードを出さない。

表示・資材URLとprecacheは0.8.16へ更新する。
