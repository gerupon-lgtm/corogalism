# T-254 縦向き固定（v0.5.7）

本編と検証ページで起動時にScreenOrientation.lock('portrait-primary')をベストエフォートで試す。PWAのmanifestもportrait-primaryを指定。ブラウザ・端末が非対応／拒否しても開始を妨げない。失敗時は端末側の縦向きロックを案内する。

全画面は自動では要求しない。本編の操作の設定、おためしページの操作欄の「縦向きで全画面」をユーザーが押したときだけ全画面化を要求し、その後に縦向き固定を試す。全画面拒否時もロック単独を試す。センサー許可処理とは独立。全画面解除時に再度強制しない。

135テスト成功。既存チュートリアル3幅とセンサー3経路成功。browser-portraitで本編／検証ページそれぞれ自動成功・全画面必須・非対応・拒否の8経路を模擬確認。実端末での固定成功は端末とブラウザに依存し、未確認。

## 本編の面と素材配置について確認したこと

本編はgenerateMazeとstageSeedによりシードから面を生成する。同じシードは再現可能で、チュートリアルと検証面は固定。themes.jsのassignThemeは正解経路の折れ点に接する壁を優先し、外周・開始とゴール付近を除外する。今後、助走距離・進行方向・床や力場の影響範囲・反発先を評価して目的に合う候補へ配置できる。適した候補がない面は配置を減らす／見送る方針が考えられる。T-254では素材配置ルールを変更しない。
