# プレイ中の自動消灯対策（v0.7.0 / T-289）

傾き操作では画面を触らないため、端末の無操作タイマーで画面が暗くなる場合がある。v0.6.31には自動消灯を防ぐ処理がなかった。v0.7.0でブラウザの画面起動ロック（Screen Wake Lock）を要求する。

- 本編のやさしい・通常、プラクティス、床の練習、既存の遊び方、動く壁の遊び方に共通。入力方式・音のON/OFF・全画面表示の有無に依存しない。
- READY・カウントダウンからプレイ中まで保持する。取得を待ってゲーム開始を遅らせない。
- 一時停止、設定、クリア、ゲームオーバー、結果、タイトル、別アプリへの切り替えでは解除する。別アプリから戻った際は従来どおり一時停止を維持し、再開操作で取り直す。
- 非対応・拒否・OSによる解除ではプレイを継続する。毎フレームの要求や、OSによる解除直後の無限再試行は行わない。再開や画面復帰で再試行する。
- 取得中に停止した場合は、遅れて取得できたものも解除する。取得・解除待ちの間に再開した場合も最終状態に合わせる。

この機能は端末の画面を一定の明るさに設定する機能ではない。HTTPS上の対応ブラウザで使用できるが、電池残量や省電力設定などにより端末側が拒否・解除する場合がある。自動明るさ調整や発熱に伴う減光の制御は含まない。[Chrome公式説明](https://developer.chrome.com/docs/capabilities/web-apis/wake-lock)。

タイトルの入口名を「動く壁のあそび方」へ変更。ユーザーの明示指示により「開発中の技術検証です（フェーズ2）」を非表示にし、その注記用の余白も取り除いた。本編・素材検証ページの画面バージョンと読み込みURLを0.7.0へ更新し、オフライン資材一覧を再生成する。

実装は `src/input/screenWakeLock.js`、本編の状態との接続は `src/main.js`。`?debug=1` の状態に `wakeLock` を追加し、対応・要求中・保持・最後の拒否理由を確認できる。通常URLでは診断情報を公開しない。

検証と公開状態は [確認記録](verification/wake-lock.md) にまとめる。Pixel6a実機の自動消灯・省電力設定・明るさ調整は未確認。
