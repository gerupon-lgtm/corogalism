## 判断と接続契約

| 対象 | 確認・判断 |
|---|---|
| T-211 / T-205 / T-217 | プラクティスはHP・制限時間なし、壁はdefaultのみ。チャレンジだけ既存のdifficulty/hp/runを使う |
| T-205 / T-207 | 衝突通知onImpactだけでダメージを処理し、HPバーの減少と被弾表示へ接続する |
| T-206 / T-213 | HP0・時間切れをゴールより優先する。クリア時の残HPは評価表示であり面数スコアには加算しない |
| T-213 / T-214 | 最初の失敗時にノーコン記録を確定し、コンティニュー後の結果を別枠へ保存する |
| 合計タイム | 既存run.clearStageの契約に従い、クリアした面のタイムだけ合計する |
| 時間 | 動き始めから計測。一時停止・設定・非表示中は除外。復帰時は手動再開 |
| 表示裁量 | 残り時間は数字＋バー。折れ回数は非表示。ノーミス面数を結果に表示 |
| 終了導線 | 途中でもランを終了でき、クリア済みの面数を記録する。プラクティスはモード選択へ戻れる |
| 作業環境 | 当初はGitなしで実装。後続依頼でGit初期化し、既存のorigin/main履歴へ接続してpush・Pages公開を完了 |
