# 音の試聴 v2 — 4分音符のパーカッション

ユーザーの「4分音符が分かるように控え目なパーカッションを追加」に対応。
100 BPM、0.6秒ごとに64拍。短い木製シェーカー風の音を重ね、各小節の最初だけ8%強くした。
メロディー・ベース・既存の音量とSEを維持。v1のWAVも比較用にそのまま保存。

- `01-bgm-toy-garden-quarter-pulse.wav`: 更新BGM、38.4秒。
- `03-gameplay-mix-quarter-pulse.wav`: SEと合わせた20秒。
- 再生成: `python tools/add-quarter-pulse.py`
- 44.1kHz / 16bit / ステレオ。ピーク約-6.36 / -6.09 dBFSで音割れなし。

ゲームへの組み込み・デプロイはしていない。音色と音量を試聴する段階。
