# Corogalism 音の試作 v1

提案の方向性でBGM・SEを作成し、聴き比べるための試作。ゲーム本体はv0.2.5のままで、音は未接続。

- `listen.html`: ローカルでも開ける試聴ページ。BGMループ・SE個別再生。
- `01-bgm-toy-garden.wav`: 100 BPM / 16小節 / 38.4秒。木琴・トイピアノ風のオリジナル合成曲。
- `02-se-showcase.wav`: 13種のSEを25.35秒で順番に再生。
- `03-gameplay-mix.wav`: BGMとSEを重ねた20秒のプレイイメージ。
- `se-*.wav`: 個別のSE。44.1kHz・16bit・ステレオWAV。

## 制作・検証

旋律・音色ともこの試作向けに作成。外部曲、録音サンプル、外部音声生成サービスは使っていない。実楽器の録音ではなく、減衰する共振音・ノイズを合成した木琴／トイピアノ風の音色。

再生成: `python tools/create-audio-prototype.py`。開発用依存はNumPy / SciPyを `../.codex-browser/audio-build` に配置。ゲーム実行環境の依存は増やしていない。

全16ファイルのPCMを検査し、無音・クリッピングなし。最大ピークは約-6.1dBFS。BGMは末尾の余韻を先頭へ回してループ化。実際の好み・耳当たりは今回の試聴で判断する。

## 未確定

音ON/OFF、ゲームイベント連動、音量保存は、試聴後の実装工程。

Chromeで3つのまとめ音源の長さ・読み込み、全13種類のSEの再生、BGMの再生と排他停止、375px幅の表示を確認。未処理例外なし。
