# T-279 序盤の区切りと広場の床 / v0.6.22

広場の仕切りの片側にだけ仕掛けがあると、もう片側が遊びにも見た目にも空白になる。公開済みの床を両区画へ分散し、反発した後にも立て直しや軌道の変化が起こるようにする。

## 序盤の区切り

両モードとも1〜8面は7×7。道の形と長短は引き続き自動生成で変わる。基本・砂・氷・重力・反重力・複合床を最初に体験した後、9面から7/8/9/11/13を混ぜる。これは導入の区切りであり、後半ほど大きくする仕組みではない。13を計算上限にせず、さらに大きな盤面の検証候補も残す。

床紹介の順序、直近4面との違いを考慮した抽選、通常10面ごとの光の滑走路は維持する。

## 広場の両側に遊ぶ場所を作る

- 砂を使う広場では、残せる既存の経路上の砂に加え、両区画に複数のつながった砂の塊を置く。スタート・ゴール周辺の砂は除く。
- 重力・反重力を使う広場では、両区画へ力場を分散する。両方を使うテーマでは両区画にそれぞれの向きを置く。力3.3、半径1.6は維持し、開始位置と仕切り出口の周辺を避ける。狭い区画では力の範囲が壁をまたぐ場合がある。壁が力を遮断する機能は追加しない。
- ひとやすみのテーマでは両区画に休憩床を確保する。他のテーマでも休憩の抽選が当たった場合は片側だけに限定しない。追加する休憩が氷上なら、その1マスを通常床の足場にする。力場の内部や取得物・とりもちとの重なりを避ける。
- とりもちのテーマでは両区画にそれぞれ2か所以上を確保する。
- 他のテーマの広場にも35％の抽選でとりもちを混ぜ、両区画に1か所ずつ置く。壁際・仕切り周辺の空きマスから乱数で選ぶ。ゴールへの軌道、正解ルート、成功率を逆算して配置しない。引っかかって勢いが止まり、結果として偶然ゴールしやすくなることも認める。

毎面へ全種類を詰め込まず、その面で選んだ床を中心にする。砂・力場・休憩・とりもちは通らない部分にも置き、キャンディ・葉っぱ・砂時計はゴールへの経路上に置く。配置と継続時の再現は同じ種で決まる。

固定傾きで反発前にゴールへ直行する道は引き続き遮る。衝突回数をゴール条件にせず、途中で傾きを変えて壁を避けるクリアと偶然の通過ゴールも認める。

## モード差と今回維持する計算

げんきは最終経路の曲がり角から決まり、制限時間は距離・曲がり角・床に必要な時間から決まる。今回の変更で式や素材の性質を変えず、完成した新配置を既存の式へ渡す。

| げんき | やさしい | 通常 |
|---|---:|---:|
| 初期値 | 40＋4×曲がり角の回数 | 同じ |
| ダメージのモード倍率 | 0.40 | 0.65 |
| 1回の衝突の上限 | 初期値の8〜14％ | 初期値の13〜22.75％ |

上限は1面目から10面目まで序盤の緩和を減らす。実際の減少には衝突速度・壁素材・面数の倍率・葉っぱの肩代わりも作用する。回復アイテム・葉っぱ・休憩の抽選はやさしいの方が多い。

制限時間は複数の見積もりのうち長い方を採用する。通常の基準は経路1マスにつき0.8〜0.55秒、曲がり角1回につき0.55秒、砂と邪魔をする力場などを加算し、序盤の従来の余裕も確保する。最低25秒。

やさしいはさらに経路1マスにつき1.6秒、曲がり角1回につき1秒、考える時間8秒、力場1か所につき1.5秒などを確保する。通常と共通の見積もりに5秒を加えた値とも比較するため、最低40秒。やさしいの床の初紹介面は最低45秒。両モードとも素材初登場の余裕6秒は残すが、通常には45秒の保証はない。単純な一定倍率の時間差ではない。

練習・チュートリアル・両おためし、物理・ダメージ係数、音、結果待機、記録の保存先は変更しない。ボール素材や綿の壁はおためし・候補として残し、本編へ自動採用しない。

検証条件と未確認範囲は[確認記録](verification/open-floor-pacing.md)。実端末の長時間の面白さ・処理負荷は公開試遊で確認する。

## あとで検討する楽しさ

床の配置を離れて見ると、動物の顔や記号に見える面。重力床が目、砂のまとまりが口のように見える配置も候補にする。近くでは床の性質を使って遊び、全体を見た時に気づく楽しさを検討する。迷路の自動生成との組み合わせ方、偶然似て見える配置と模様を意図して混ぜる配置の扱いは未確定。今回の本編には未実装。
